# 指挥官加入 Launcher 候选列表的最小改动说明

## 结论

如果目标只是让一个新指挥官出现在 `Launcher.SC2Map` 的候选指挥官选择界面，至少需要修改 `Launcher.SC2Map` 内部的三类文件：

```text
1. MapScript.galaxy
2. Base.SC2Data/GameData/UserData.xml
3. zhCN.SC2Data/LocalizedData/GameStrings.txt
```

这里说的是实际启动的打包版：

```text
Maps/XM/Launcher.SC2Map
```

不要误改成：

```text
LauncherAuto.SC2Map
LauncherKerrigan.SC2Map
```

除非实际启动入口明确就是这些文件夹版地图。

## 1. MapScript.galaxy

`MapScript.galaxy` 中需要调整指挥官数量常量：

```galaxy
const int gv_commanderNum = 8;
```

注意：`gv_commanderNum` 在这个 Launcher 脚本中表示**最大索引**，不是数量。

换算关系：

```text
9 个指挥官  => gv_commanderNum = 8
10 个指挥官 => gv_commanderNum = 9
11 个指挥官 => gv_commanderNum = 10
```

原因是脚本中的循环通常是：

```galaxy
for ( ; lv_i <= gv_commanderNum ; lv_i += 1 )
```

所以它会遍历：

```text
0..gv_commanderNum
```

如果把 `gv_commanderNum` 当成数量来写，就会多创建一个按钮，访问不存在的 `CommanderPreset` 数据，可能导致指挥官 UI 初始化失败。

## 2. Base.SC2Data/GameData/UserData.xml

这个文件定义 Launcher 候选列表本体。

需要修改 `CommanderPreset` 中的三个 Count：

```xml
<Fields Id="Commander" Type="String" Count="9"/>
<Fields Id="Por" Type="Text" Count="9"/>
<Fields Id="CommanderPortrait" Type="Image" Count="9"/>
```

如果候选总数是 9 个，就写：

```text
Count="9"
```

如果候选总数是 10 个，就写：

```text
Count="10"
```

然后为新增指挥官补三类字段。

### 2.1 按钮头像

示例：阿巴瑟作为第 9 个候选，索引为 8。

```xml
<Image Image="Assets\Textures\btn-commander-abathur.dds">
    <Field Id="CommanderPortrait" Index="8"/>
</Image>
```

### 2.2 指挥官 ID

```xml
<String String="Abathur">
    <Field Id="Commander" Index="8"/>
</String>
```

这个字符串就是写入 Bank 的 Commander ID。

例如：

```text
Abathur
Kerrigan
Alarak
```

### 2.3 大头像 / 显示文本引用

```xml
<Text Text="UserData/CommanderPreset/ID_Por_008">
    <Field Id="Por" Index="8"/>
</Text>
```

这个 `ID_Por_008` 必须在 `GameStrings.txt` 中有对应文本。

## 3. zhCN.SC2Data/LocalizedData/GameStrings.txt

这里要补上 `Por` 字段引用的文本。

阿巴瑟示例：

```text
UserData/CommanderPreset/ID_Por_008=<img path="Assets\Textures\ui_commanderportrait_abathur.dds" width="62" height="76"/>
```

凯瑞甘示例：如果她是第 10 个候选，索引为 9：

```text
UserData/CommanderPreset/ID_Por_009=<img path="Assets\Textures\ui_commanderportrait_kerrigan.dds" width="62" height="76"/>
```

## 三个文件必须一致

假设要新增第 10 个指挥官，索引是 9，那么必须同时满足：

```text
MapScript.galaxy:
  gv_commanderNum = 9

UserData.xml:
  Commander Count = 10
  Por Count = 10
  CommanderPortrait Count = 10
  Commander Index 9 = 新指挥官 ID
  CommanderPortrait Index 9 = 按钮头像
  Por Index 9 = UserData/CommanderPreset/ID_Por_009

GameStrings.txt:
  UserData/CommanderPreset/ID_Por_009 = 大头像文本
```

如果三者不一致，常见结果包括：

```text
1. 指挥官按钮不显示
2. 候选界面打不开
3. 点击按钮后 Bank 写入空 Commander
4. 头像或说明为空
5. UI 创建循环越界导致整个 CommanderUI 中断
```

## 静态检查清单

修改后至少检查：

```powershell
Select-String -Path ".\MapScript.galaxy" -Pattern "gv_commanderNum"
Select-String -Path ".\Base.SC2Data\GameData\UserData.xml" -Pattern 'Count="','String="Abathur"','String="Kerrigan"','ID_Por_008','ID_Por_009'
Select-String -Path ".\zhCN.SC2Data\LocalizedData\GameStrings.txt" -Pattern 'ID_Por_008','ID_Por_009','ui_commanderportrait_abathur','ui_commanderportrait_kerrigan'
```

检查关系：

```text
候选数量 N
最大索引 N-1
MapScript.galaxy: gv_commanderNum = N-1
UserData.xml: 三个 Count = N
新增指挥官 Index = N-1
GameStrings.txt: ID_Por_00X 存在
```

## 只显示候选不等于可玩

以上改动只能保证：

```text
1. Launcher 候选界面能显示新指挥官
2. 点击后 SaveBank 能把 Commander 写入 CampaignXCore.SC2Bank
```

但这不保证进入地图后能正常游玩。

要让指挥官真正可玩，还需要额外接好：

```text
1. XMFinal.SC2Mod/DocumentInfo 依赖对应指挥官 Mod
2. XMCore.SC2Mod 中存在 CommanderAch/<Commander>
3. XMFinal 初始化分支能识别该 Commander
4. XMFinal InitializeBase 能创建对应基地、工蜂、英雄或 CoopCaster
5. XMCore 的 CU_GPInit 能初始化该指挥官面板
6. 指挥官独立 Mod 中有 Unit / Ability / Button / Actor / Upgrade 等数据
7. 特殊剧情地图需要额外 MapScript 分支
```

因此要区分两个目标：

```text
Launcher 候选显示：只改 Launcher.SC2Map 内部 3 类文件
指挥官可玩：还要改 XMCore / XMFinal / 指挥官 Mod / 地图脚本
```

## 常见错误

### 1. 把 gv_commanderNum 当成数量

错误：

```galaxy
const int gv_commanderNum = 10;
```

同时：

```xml
Count="10"
```

这会让脚本遍历 0..10，共 11 个索引，但 UserData 只有 10 个候选。

正确：

```text
10 个候选 => gv_commanderNum = 9
```

### 2. 只改 Count，不补 Index 字段

如果 Count 改成 10，但没有补：

```text
Commander Index 9
CommanderPortrait Index 9
Por Index 9
```

则第 10 个按钮数据为空或异常。

### 3. 只改 UserData，不补 GameStrings

如果 `Por Index 9` 指向：

```text
UserData/CommanderPreset/ID_Por_009
```

但 `GameStrings.txt` 没有该行，大头像显示会缺失。

### 4. 改错入口

实际启动的是：

```text
Maps/XM/Launcher.SC2Map
```

但修改了：

```text
LauncherAuto.SC2Map
```

则游戏内不会看到任何变化。

### 5. 一次加多个指挥官

建议顺序：

```text
先恢复 Abathur
实机确认候选界面正常
再加 Kerrigan
最后再考虑 Alarak
```

不要一次性改到 11 个候选，否则难以定位是哪个候选、哪个头像、哪个文本或哪个 Index 出错。
