# 2026-05-27 凯瑞甘 / 阿巴瑟 runtime 对齐修正

时间：2026-05-27

## 本轮目标

不是继续做“能不能进图”的冒烟，而是直接排查当前 `合作指挥官版起义狂潮` 运行线里，为什么合作指挥官的实际兵种 / 技能 / 开场单位会和官方合作模式口径对不上。

## 本轮确认到的真实问题

### 1. 凯瑞甘缺少合作面板初始化链

文件：

- `合作指挥官版起义狂潮/Mods/XM/XMFinal.SC2Mod/Base.SC2Data/LibE0EAE146.galaxy`

现象：

- `XMFinal` 在初始化凯瑞甘时，只给玩家补了：
  - `CommanderLevel`
  - `KerriganCommander`
  - `K5PrimalSlash`
  - `K5PsiStrike`
  - `K5ChainLightning`
  - `K5Cooldowns`
  - `K5Fury`
  - `KerriganVoidCoopEnergyRegen`
- 然后直接生成 `K5Kerrigan`
- 但没有像阿巴瑟、雷诺、扎加拉那样调用 `CommanderPanelInit(...)`

结论：

- 这会让凯瑞甘少走一条合作模式面板 / GP 初始化链。
- 这不是“UI 小问题”，而是实际 runtime 初始化缺口。

### 2. 凯瑞甘开场小队是地图层硬编码，不是按当前合作解锁形态取值

文件：

- `合作指挥官版起义狂潮/Mods/XM/XMFinal.SC2Mod/Base.SC2Data/LibE0EAE146.galaxy`

现象：

- `libE0EAE146_gf_KerriganCreateMapStartSquad`
- `libE0EAE146_gf_KerriganCreateCargoSquad`

此前硬编码的是：

- `HotSRaptor`
- `Hydralisk`

其中 `Hydralisk` 这条会把实际开场刺蛇落成不能走潜伏者线的旧条目，而不是当前这条合作口径里带潜伏者分支的 `HydraliskLurker`。

结论：

- 当前项目里，“凯瑞甘的兵种是否正确”不只由指挥官 Catalog 决定，还会被地图层的开场小队硬编码直接带偏。

### 3. 阿巴瑟的开场小队仍在用旧 generic 单位 ID

文件：

- `合作指挥官版起义狂潮/Mods/XM/XMFinal.SC2Mod/Base.SC2Data/LibE0EAE146.galaxy`

现象：

- `libE0EAE146_gf_AbathurCreateMapStartSquad`
- `libE0EAE146_gf_AbathurCreateCargoSquad`

此前基础值仍是：

- `Ravager`
- `SwarmHostMP`
- `Queen`
- `Leviathan`

而当前 Abathur 模组里实际已经有更接近合作口径的条目：

- `RavagerAbathur`
- `SwarmHost`
- `QueenCoop`
- `HotSLeviathan`

结论：

- 即使 `XMAbathur.SC2Mod` 里官方相关单位已存在，地图层仍可能把玩家开场小队拉回旧 generic 链。

## 本轮已修改

文件：

- `合作指挥官版起义狂潮/Mods/XM/XMFinal.SC2Mod/Base.SC2Data/LibE0EAE146.galaxy`

### 已做修正

1. 给凯瑞甘初始化补上：

- `libE0EAE146_gf_CommanderPanelInit("CoopCasterKerrigan", "Kerrigan");`

2. 把凯瑞甘开场 / cargo 小队里的刺蛇从：

- `Hydralisk`

改为：

- `HydraliskLurker`

覆盖：

- `light`
- `heavy`
- `hero`

3. 把阿巴瑟开场 / cargo 小队的基础单位链对齐为：

- `RavagerAbathur`
- `SwarmHost`
- `QueenCoop`
- `HotSLeviathan`

不再在 runtime 入口默认回退到：

- `Ravager`
- `SwarmHostMP`
- `Queen`
- `Leviathan`
