# 官方凯瑞甘形态、威望、建筑与幼虫链路说明

日期：2026-06-02

## 结论

官方合作指挥官凯瑞甘的主身份不是两个互相独立的英雄单位。官方入口是 `CCommander id="Kerrigan"` 指向 `PlayerCommanders;ZergKerrigan`，主英雄单位是 `K5Kerrigan`，潜地形态是 `K5KerriganBurrowed`。所谓“刀锋女王 / 人类形态”的差异，主要体现在同一套 `K5Kerrigan` 英雄命令卡上的技能启用/禁用，以及 `KerriganInfestedCosmetic` / `KerriganGhostCosmetic` 外观升级切换。

建筑链路方面，官方凯瑞甘仍是虫族范式：`Drone` 通过 `ZergBuild` 变形为建筑，不是 SCV 式施工。当前 Mod 已经做了第一阶段私有化：`DroneKerrigan -> ZergBuildKerrigan -> *Kerrigan` 私有建筑链已接上。

幼虫/变异链路方面，官方兵种主要由 `LarvaTrain` / `LarvaTrainSwarm` / 单位变异能力串起来；当前 Mod 还没有 `LarvaKerrigan` / `LarvaTrainKerrigan`，因此“基础建筑私有化”已推进，但“幼虫生产与作战单位完整私有化”仍未闭环。

## 官方两套技能形态

`K5Kerrigan` 命令卡同时出现默认刀锋女王技能和第三威望的人类/幽灵技能。真正决定哪套可用的是指挥官默认升级和威望启用/禁用。

默认升级在 `userdata.xml:32523-32530`：

| 默认升级 | 作用口径 |
| --- | --- |
| `KerriganCommander` | 凯瑞甘基础指挥官升级 |
| `K5PrimalSlash` | 默认启用 `PrimalSlash` |
| `K5PsiStrike` | 默认启用 `PsiStrikeWalk` |

`K5Kerrigan` 命令卡上的关键技能：

| 技能口径 | Button / Ability |
| --- | --- |
| 刀锋女王突进 | `PrimalSlash -> PrimalSlash,Execute` |
| 刀锋女王穿刺/冲刺 | `PsiStrike -> PsiStrikeWalk,Execute` |
| 吸收光环 | `KerriganVoidCoopEconDrop -> KerriganVoidCoopEconDrop,Execute` |
| 禁锢波/定身波 | `KerriganVoidCoopCrushingGripWave -> KerriganVoidCoopCrushingGripWave,Execute` |
| 人类/幽灵单体技能 | `MindBolt -> MindBolt,Execute` |
| 人类/幽灵范围控制 | `PsionicLift -> PsionicLift,Execute` |

官方 `userdata.xml:10104-10127` 的第三威望定义把这件事写得很直接：

| 字段 | 内容 |
| --- | --- |
| `DisableAbil` | `PsiStrikeWalk` |
| `DisableAbil[1]` | `PrimalSlash` |
| `EnableAbil` | `PsionicLift` |
| `EnableAbil[1]` | `MindBolt` |
| `SuppressUpgrade` | `KerriganInfestedCosmetic` |
| `SecondaryUpgradesSelf` | `KerriganGhostCosmetic` |
| `SecondaryUpgradesShared` | `CommanderPrestigeKerriganAssimilationAuraShared` |

所以更准确的理解是：

- 非第三威望：同一个 `K5Kerrigan` 使用刀锋女王技能表现。
- 第三威望：同一个 `K5Kerrigan` 禁用 `PrimalSlash` / `PsiStrikeWalk`，启用 `MindBolt` / `PsionicLift`，并切换到幽灵/人类外观。
- 这不是“再造一个 HumanKerrigan 主单位”的模式。

当前 Mod 在 `XMKerrigan.SC2Mod/Base.SC2Data/GameData/UserData.xml:11079-11103` 也保留了同样的第三威望切换定义。

## 官方三个威望效果

官方 `prestiges.json` 和原始 XML 共同指向三个 `PlayerPrestige`：

| 威望 ID | 直接定义 | 深层效果链 |
| --- | --- | --- |
| `CommanderPrestigeKerriganCreep` | 禁用 `NydusNetwork`，补充 `KerriganCreep1` | `upgradedata.xml:579-585` 调整恶性菌毯攻速/回血、Queen creep 速度、Queen 建造菌毯肿瘤目标 |
| `CommanderPrestigeKerriganAbilities` | 补充 `KerriganAbilities1/2/3` | `upgradedata.xml:591-600` 设置 rage 转换 chance，并扣减 `PrimalSlash`、`PsiStrikeDamage`、`PsionicLiftDamage` 等基础伤害/吸收；`effectdata.xml:711-818` 把 rage 转换注入 `PrimalSlashInitialSet` 和 `PsiStrikeWalk` |
| `CommanderPrestigeKerriganAssimilationAura` | 禁用 `PsiStrikeWalk` / `PrimalSlash`，启用 `PsionicLift` / `MindBolt`，切外观 | `upgradedata.xml:615-625` 的 `CommanderPrestigeKerriganAssimilationAuraShared` 调整 `KR0` 到 `KR5` 的资源奖励 |

这三个威望中，第三威望最直接对应用户提到的“人类形态技能不同”。第一、第二威望更多是修改建筑/菌毯能力和技能数值/触发效果，不是切换主英雄单位。

但快速搜索当前 `XMKerrigan.SC2Mod/Base.SC2Data/GameData` 未发现：

- `LarvaKerrigan`
- `LarvaTrainKerrigan`
- `TrainQueenKerrigan`

因此当前状态应表述为：

- 建筑链第一阶段私有化已完成。
- 幼虫训练仍在共享 `LarvaTrain` / `LarvaTrainSwarm` / `LarvaTrainSwarmling` 框架下。
- 皇后仍有 `TrainQueen -> QueenCoop` / `SwarmQueen` 相关共享或 alias 风险。
- 作战单位仍大量沿用共享 ID，例如 `Hydralisk`、`Ultralisk`、`BroodLord`、`MutaliskBroodlord`、`Zergling`，还不能称为 Nova 式完全私有 commander module。

## 串联模型

把官方与当前 Mod 合起来看，凯瑞甘链路应按下面模型理解：

```text
CommanderData
  Kerrigan -> PlayerCommanders;ZergKerrigan

PlayerCommanders / UserData
  ZergKerrigan
    -> default upgrades: KerriganCommander, K5PrimalSlash, K5PsiStrike
    -> prestiges:
       P1 creep: disable NydusNetwork + creep supplement
       P2 abilities: rage conversion + skill damage/value rewrite
       P3 assimilation aura: disable PrimalSlash/PsiStrikeWalk, enable MindBolt/PsionicLift, switch cosmetic

Hero Unit
  K5Kerrigan / K5KerriganBurrowed
    -> same command card hosts both Queen-of-Blades and human/ghost skill buttons
    -> prestige controls which ability set is active

Economy / Buildings
  Official: Drone -> ZergBuild -> Hatchery/SpawningPool/HydraliskDen/Spire/UltraliskCavern/Nydus/Spine/Spore...
  Current Mod: DroneKerrigan -> ZergBuildKerrigan -> *Kerrigan private buildings

Larva / Army
  Official: Larva -> LarvaTrain/LarvaTrainSwarm -> Zergling/Hydralisk/Ultralisk/MutaliskBroodlord...
  Official morph: Mutalisk/Corruptor -> BroodLord
  Current Mod: still mostly shared LarvaTrain/LarvaTrainSwarm; MutaliskMorphToBroodLord button exists
```

## 后续需要补齐的点

1. 幼虫私有化：补 `LarvaKerrigan`、`LarvaTrainKerrigan`，并追 `HatcheryKerrigan/LairKerrigan/HiveKerrigan` 的 larva spawn behavior/effect，避免幼虫出生后回到共享 `Larva`。

2. 皇后私有化：决定 `QueenCoop` / `SwarmQueen` 是保留 alias 还是创建 `QueenKerrigan` / `TrainQueenKerrigan`。如果要避免虫族指挥官互相污染，推荐继续私有化。

3. 作战单位私有化：当前 `Hydralisk`、`Ultralisk`、`BroodLord`、`Zergling` 等仍是共享 ID 或 alias；若按 Nova 模式推进，需要逐个定义 Kerrigan-private runtime unit，并同步 train/morph/research/requirement。

4. Requirement 私有化：建筑已变成 `*Kerrigan` 后，后续应补 `HaveSpawningPoolKerrigan`、`HaveHiveKerrigan`、`HaveSpireKerrigan` 等需求，避免按钮显示/科技解锁仍检查共享建筑。

5. 建筑研究面板清理：`SpawningPoolKerrigan`、`HydraliskDenKerrigan`、`EvolutionChamberKerrigan`、`UltraliskCavernKerrigan` 等如果继续从 parent 继承共享研究能力，后续仍可能串线。

6. SC2 运行时验证：本文是静态链路追踪，没有进游戏验证。需要测试图确认开局工蜂、建筑变形、幼虫出生、幼虫训练、异龙变巢虫领主、威望三技能切换是否与预期一致。
