## 6. 这条线里最关键的实现特征

- 跳虫不是单纯“跳虫升级”，而是 `Zergling`、`SpawnedZergling`、`ZerglingToxic`、`PrimalZergling2` 分层。
- 雷兽不是普通科技树，四个购买项直接挂在单位卡上。
- 莽兽同样是单位卡上的 3 个购买项，不是传统建筑研究。
- 利维坦在源包里更像共享强化链，核心要盯 `Range` 和相关共生体/面板链。
- 兵种、建筑、按钮三者在这条线里是分离的，不能只认“名称相似”。

## 7. 适合后续对照当前实现的优先级

1. 先对照 `PrimalZergling2` / `HotSMetabolicBoost` / `HotSZerglingHealth` / `HotSZerglingFrenzy`
2. 再对照 `Brutalisk*` 三条购买项
3. 再对照 `Ultralisk*` 四条购买项
4. 最后补 `Abathur*` 系列的飞龙、守护者、穿刺者、潜伏者、宿主、吞噬者、巢虫领主科技
