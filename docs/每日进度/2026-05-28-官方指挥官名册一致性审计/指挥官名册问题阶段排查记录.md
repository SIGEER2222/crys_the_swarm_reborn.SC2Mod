## Stetmann 已确认口径

机械蟑螂不是普通幼虫生产缺口。当前按以下链路记录：

- 机械感染者技能 `InfestorStetmannInfestBuilding` 生成 `RoachStetmannEgg`。
- `RoachStetmannEggMorph -> RoachStetmann`。
- 因此 `RoachStetmann` 不再列为基础生产链漏收。

同时过滤：

- `OverseerStetmann <-> OverseerStetmannSiegeMode`：机械眼虫超距视界模式切换。
- `LurkerStetmannBurrowed`：机械潜伏者埋地形态。
- `SpineCrawlerUprootedStetmann`、`SporeCrawlerUprootedStetmann`：爬虫拔起形态。
- `GaryStetmann`：英雄初始化项。

## 继续排查的优先级

1. Stukov：等用户允许后只运行官方数据生成，验证 Stukov 四个单位补入、三个误收消失。
2. Nova：确认 `ReaperNova/MercReaper` 是否是旧项；当前高疑似误收或错误映射。
3. Mengsk：给冲锋队换装、攻城坦克攻城模式、维京突击模式补 `variant/morph` 关系。
4. 神族指挥官：处理 Gateway/Observer 继承面板噪音，并修正 `Immortal/Phoenix/Scout/Colossus` 等生产链被抓成 `Probe/ProtossBuild` 建筑入口的问题。
5. Terran 指挥官：区分 SCV 通用建筑是真的缺建筑名册，还是继承面板噪音；不要直接过滤掉建筑缺口。
6. Zagara：单独确认合作模式下 `Corruptor -> BroodLord` 是否可用，再决定补链或过滤。

## 后续避免踩坑

- 不要把 `command_card_only` 的数量直接当作缺单位数量。
- 不要把模式切换、召唤、临时炮台、治疗棒、埋地/拔起形态当作普通生产链。
- 不要把 `合作指挥官版起义狂潮/Mods/XM/**/CommanderAch` 当官方来源。
- 官方设计基准仍按 `游戏数据/官方合作指挥官/commanders/<Commander>/`，必要时回追 `references/sc2-build-96883-casc-export/`。
- 如果要改官方 JSON，先改提取器规则，再由用户确认是否重新生成；不要手改 JSON 当最终方案。
