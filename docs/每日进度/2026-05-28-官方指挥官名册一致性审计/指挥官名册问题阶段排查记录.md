## 高置信问题 2：Stetmann 机械蟑螂缺生产链

当前文件：

`游戏数据/官方合作指挥官/commanders/Stetmann/units.json`

当前问题：

| 单位 | 当前状态 | 应有生产链 |
| --- | --- | --- |
| `机械蟑螂 / RoachStetmann` | 无 `production` | `LarvaStetmann / LarvaTrainStetmann,Train4 / RoachStetmann` |

相关 CASC 证据：

文件：

`references/sc2-build-96883-casc-export/mods/starcoop/commanders/egonstetmann.sc2mod/base.sc2data/gamedata/abildata.xml`

关键片段：

```xml
<CAbilTrain id="LarvaTrainStetmann">
  ...
  <InfoArray index="Train4" Time="27">
    <Button DefaultButtonFace="RoachStetmann" Requirements="HaveRoachWarrenStetmann"/>
    <Unit value="RoachStetmann"/>
  </InfoArray>
</CAbilTrain>
```

连带影响：

- `机械破坏者 / RavagerStetmann` 当前能识别为 `RoachStetmann -> MorphToRavagerStetmann`。
- 但 `RoachStetmann` 自身没有从幼虫生产的入口，导致可读报告会缺少完整链路。

建议处理：

1. 给 Stetmann 增加 `RoachStetmann` 生产覆盖：
   - `producer_unit_id = LarvaStetmann`
   - `button_face = RoachStetmann`
   - `abil_cmd = LarvaTrainStetmann,Train4`
2. 重新生成官方 JSON 前先保留当前回退状态，避免覆盖用户手动回退。
3. 修完提取器后再由用户确认是否执行生成。
