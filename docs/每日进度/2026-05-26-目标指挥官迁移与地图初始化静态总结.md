### 兵种、建筑迁移

目标范围内，兵种和建筑的静态迁移基本完成。

已静态闭环的模块：

- `XMAlarak`
- `XMArtanis`
- `XMFenix`
- `XMKarax`
- `XMKerrigan`
- `XMRaynor`
- `XMVorazun`
- `XMZagara`
- `XMZeratul`

`XMAbathurReborn` 也可按已闭环处理，但有两个并存改名项：

| 官方 ID | 当前 ID | 判断 |
|---|---|---|
| `ImpalerAbathur` | `ImpalerAbathurReborn` | 更像为了和旧 `XMAbathur` 并存而改名，不按硬缺口处理。 |
| `RavagerAbathur` | `RavagerAbathurReborn` | 更像为了和旧 `XMAbathur` 并存而改名，不按硬缺口处理。 |

`XMAbathur` 是旧阿巴瑟并存模块，有自己的 `CommanderAch/Abathur` 与旧 ID 数据。当前官方迁移报告把官方阿巴瑟主落点统计到 `XMAbathurReborn`，因此不要把 `XMAbathur` 与 `XMAbathurReborn` 混成同一个完成状态。

初始化已完成第一轮 runtime 与地图本地分支补齐，但仍没有 SC2 进图验收，不能按实机闭环处理。
