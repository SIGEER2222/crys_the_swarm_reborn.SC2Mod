# 2026-05-27 官方合作突变因子简版分类

## 结论

- 官方 live 数据里，没有直接叫“正面因子”或“环境因子”的顶层分类。
- 这两个名字更适合当接入层的业务分类，而不是官方原始 taxonomy。
- 但官方数据里，确实能拆出两类很稳定的实现族：
  - `正面因子`：给敌方/战场额外强化、额外单位、额外复活压力。
  - `环境因子`：改资源、改规则、刷资源点、插入经济/交互干预。

  - `合作指挥官版起义狂潮/Mods/XM/XMMutator.SC2Mod/zhCN.SC2Data/LocalizedData/TriggerStrings.txt`

说明：

- 官方 `zhCN` 里大量突变因子名是 `Auto - Copied from enUS Locale`，所以显示名很多仍是英文。
- 当前项目里的中文名，很多是基于同一个官方触发/分类 ID 做的本地化；因此可以用“同 ID”稳定反查官方内部名。

## 接入建议

如果后续要在 `XMMutator` 或统一 mutator 面板里接“正面因子/环境因子”，建议不要新造第三套官方名表，而是直接维护一层业务分类：

1. 先保留官方内部键：
   - 例如 `HeroesFromTheStorm`、`Reanimator`、`DropPods`、`OrderCosts`、`MinedOut`
2. 再给每个键挂一层业务分类：
   - `positive`
   - `environment`
3. 中文显示名继续走本地化表，不反向污染官方键。

这样后面继续补其他因子时，只要继续按官方内部键挂分类即可，不会把 UI 分类和官方实现名混在一起。
