## 关键处理

1. 地图 live `DocumentInfo/DocumentHeader` 改为依赖本地扩展 Mod：

```text
file:Mods/7vs1/CoopZeroPop.SC2Mod
```

2. 扩展 Mod live 仍保留官方依赖：

```text
bnet:Void Multi (Mod)/0.0/999,file:Mods/VoidMulti.SC2Mod
bnet:Co-op Mission/0.0/999,file:Mods/StarCoop/StarCoop.SC2Mod
```

3. `LibKPVP.galaxy` live-only 注入：

```text
libKPVP_gf_codex_init_7vs1_test_commanders
libKPVP_gf_codex_init_test_player
libKPVP_gf_codex_ensure_start_units
libKPVP_gf_codex_start_point
```

作用：

```text
设置 P1-P7 commander
加入 CommanderPlayers runtime
为 P1-P7 在地图 StartLoc 创建主基地和 5 个工人
为 Abathur/Dehaka/Horner/Mengsk/Tychus 这类特殊分组补 runtime group
```

主基地/工人创建优先使用 commander 专属映射：

```text
TerranHorner -> HHCommandCenter / HHSCV
TerranTychus -> TychusCommandCenter / TychusSCV
TerranMengsk -> CommandCenterMengsk / SCVMengsk
ZergStukov -> SICommandCenter / SISCV
ZergDehaka -> DehakaHatchery / DehakaDrone
ZergStetmann -> HatcheryStetmann / DroneStetmann
其他 Terr/Zerg/Prot -> CommandCenter/Hatchery/Nexus + SCV/Drone/Probe
```

4. `LibKPVP.galaxy`、`LibKCOR.galaxy`、`LibKMIS.galaxy` live-only 注入安全出生点函数，并把 `PlayerStartLocation()` 替换成安全函数。

原因：

本地 `SC2Switcher` 直开地图时，2-7 槽位不是正常 Battle.net lobby user slot。原合作 Mod 会对这些槽位调用 `PlayerStartLocation()`、主基地搜索、英雄生成；如果不提供安全点位和主基地锚点，会出现空 point/unit 错误。

5. `LibKMIS.galaxy` live-only 屏蔽 `PlayerAddReward(...)`。

原因：

本地 `SC2Switcher` 直开没有 Battle.net reward 授权。`VoicePackCommanderDefaultApply` 里给默认语音包发 reward 会触发：

```text
'libKPVP_gt_StartingTech_Func'出现触发器错误：无权调用'PlayerAddReward'
```

本地 smoke test 不需要发 reward，因此 live 副本中直接省略该调用。

说明：

当前 `commander-rosters` 只是“7vs1 归属对照 + 官方 co-op 名册补全”的比较导出，不是 7vs1 游戏内真正的可建造/可产出闭包。它现在的作用是帮我们看清 replay 包里 `TechUnit` 直接挂了哪些 commander，而不是替代游戏里的 Requirement/Build/Train 逻辑。

现在能确定的口径是：

1. `TechUnit` 里的 `Commander` 字段只说明归属，不等于最终可造/可产出。
2. 真实按钮闭包还要再过 `DefaultAbilityCommands`、`DefaultUpgrades`、`Requirement`、`SpawnRace` 和 runtime 初始化。
3. 因此，7vs1 里看到的“指挥官单位-可建造和可产出”可能和官方合作模式不同，不能再直接拿官方 `roster.json` 当最终答案。

为了不漏本地测试必需的开局主基地/工人，导出脚本还会追加 `launch-7vs1-coop-test.ps1` 使用的 starting anchors，例如 `HHCommandCenter / HHSCV`、`TychusCommandCenter / TychusSCV`、`CommandCenterMengsk / SCVMengsk`。

`ZergStetmann` 与 `TerranMengsk` 不在 replay 提取的 `pkg01 GameData/UserData.xml` 的 `PlayerCommanders` 静态实例里，因此在 JSON/Markdown 里标为 `official fallback`。其他 commander 的 7vs1 `TechUnit` 归属仍保留在 JSON 的 `sevenVsOneTechUnitRoster` 中，用来对照 replay 包直接声明了哪些 tech 归属。

## 已排除的问题

1. 旧黑屏/进图前退出不是当前主问题；本轮能进入 Galaxy 运行期并生成 `ScriptError.txt`。
2. 只加入 1-7 commander runtime 不够；非 active 槽位缺主基地会导致 `libKMIS_gt_CM_HeroSpawn_Func` 空 unit。
3. Tychus 不适合作为默认非本地槽位；其 squad bar UI 会在没有本地 dialog control 时刷 `DialogControlSetPropertyAsFixed` 错误。因此默认 P7 改为 Vorazun。
