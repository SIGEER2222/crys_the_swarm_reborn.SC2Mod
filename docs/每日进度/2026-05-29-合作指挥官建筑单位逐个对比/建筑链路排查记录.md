## 本轮修正口径

旧报告只按“当前指挥官模块 + XMCore/XMFinal + 官方镜像”判断，会把 `XMFinal` 实际运行时已经加载的其他指挥官模块误判成“只在官方合作镜像有 CUnit”。

本轮脚本已改成：

1. 扫描 XML 前剔除 `<!-- ... -->` 注释，避免注释里的旧 `AbilArray` / `InfoArray` 误报。
2. 从 `XMFinal.SC2Mod/DocumentInfo` 递归建立 active 运行闭包。
3. Catalog 层级改为：当前指挥官模块、`XMCore/XMFinal`、`XMFinal` 运行闭包、官方底层基础镜像、官方合作镜像。
4. 只有同一个 `CUnit` 同时挂了对应 `AbilArray`，并且命令卡里露出 `AbilCmd="技能,命令"`，才算“命令卡露出产物”。
5. 额外抽取旧线初始化开局单位：`InitializeBase` 特判 + `XMCore` 的 `CommanderAch.CommandCenter/Worker/SecondUnit`。
6. 额外抽取 `InfoArray/Button` 的 `Requirements` 和 `State`，用于判断按钮是可见风险、科技限制还是残留线索。
