# 2026-05-26 所有指挥官兵种建筑静态整理

## 口径

- 当前环境没有 SC2，本文只基于 `UnitData.xml`、`UserData.xml` 和中文 `GameStrings.txt` 做静态整理，不代表进图或编辑器验收通过。

## 静态结论与风险

- 19 个指挥官均能从 `CommanderAch` 解析到开局主基地、第二单位和工人。
- 小型后加模块（如蒙斯克、米拉汉、德哈卡、斯旺、泰凯斯等）单位归属较清楚；老指挥官模块包含较多通用复制数据，本文已做静态过滤，但仍可能把少量剧情/共享对象纳入。
- 报告中的“技术对象”主要用于追踪 XML 迁移完整性，不应直接等同于玩家可操控单位。
- 后续如果继续补迁移，建议优先看明细 CSV 中某指挥官的建筑和兵种缺口，再反查对应 `UnitData.xml`、按钮、训练能力和地图初始化引用。
