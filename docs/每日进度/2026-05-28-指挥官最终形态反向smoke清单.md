# 指挥官最终形态反向 smoke 清单

## 目标

- 以 `游戏数据/官方合作指挥官/官方合作指挥官兵种建筑总表-中文.md` 为人工校对口径
- 反向检查当前指挥官实现是否已经表现出“最终可玩形态”
- 重点不是 Catalog 是否存在，而是：
  - 是否能生产
  - 是否会被正确替换/升级
  - 是否不会把基础体和终态同时错误暴露

## 高优先级 smoke 点

### 凯瑞甘

- 跳虫最终应表现为 `腾跃虫`，不能仍停留在基础跳虫口径
- 异龙应支持升级到 `巢虫领主`
- 英雄凯瑞甘技能链需与当前等级/解锁同步检查

### 阿巴瑟

- 蟑螂系应检查为：
  - `蟑螂 -> 尸毒蟑螂 / 恶毒蟑螂 -> 秽形虫`
- 不应把三种“蟑螂”当成三个并列终态兵种直接摆面板
- `守护者 / 吞噬者` 应作为异龙进化分支检查
- `莽兽` 应按“任意满生物质地面作战单位的终极进化”检查
- `利维坦` 应按“任意满生物质空中作战单位的终极进化”检查

### 斯台特曼

- 跳虫 -> 爆虫
- 刺蛇 -> 潜伏者
- 腐化者 -> 巢式战列空母
- 监督者/监督者模式不要被误当成两个并列终态兵种

### 斯旺 / 霍纳与汉

- 形态切换单位不要被当成两个并列科技树终态
- 重点看：
  - `Hellion / Hellbat`
  - `VikingFighter / VikingAssault`

### 蒙斯克

- 冲锋队多武装形态需要确认是“同基础单位的武装切换/升级”，不是互相独立的新兵种
- 攻城坦克、维京、铁鸦姿态体不要重复算终态

### 德哈卡

- 各原始单位的等级进化体需要按最终形态重新核
- 不要把明显等级链上的前后体都当成并列最终兵种

2. 再修 `Stetmann`
3. 然后清 `Swann / Horner / Mengsk`
4. 最后收 `Dehaka`
