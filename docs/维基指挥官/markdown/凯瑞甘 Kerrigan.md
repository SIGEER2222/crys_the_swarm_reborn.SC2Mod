## 主要部队

[![Btn-unit-zerg-zergling-raptor.png](<./凯瑞甘 Kerrigan - 星际争霸中文维基 - 灰机wiki - 北京嘉闻杰诺网络科技有限公司_files/Btn-unit-zerg-zergling-raptor.png>)](https://starcraft.huijiwiki.com/wiki/%E5%90%88%E4%BD%9C%E4%BB%BB%E5%8A%A1/%E5%87%AF%E7%91%9E%E7%94%98/%E8%B7%B3%E8%99%AB "合作任务/凯瑞甘/跳虫")迅捷的肉搏型生物，可以越过障碍物并从一段距离外跳向目标。拥有更强的伤害能力。可变异为爆虫。  
  
可以对地  
  
12级时升级[跳虫](https://starcraft.huijiwiki.com/wiki/%E5%90%88%E4%BD%9C%E4%BB%BB%E5%8A%A1/%E5%87%AF%E7%91%9E%E7%94%98/%E8%B7%B3%E8%99%AB "合作任务/凯瑞甘/跳虫") [![Btn-unit-zerg-queen.png](<./凯瑞甘 Kerrigan - 星际争霸中文维基 - 灰机wiki - 北京嘉闻杰诺网络科技有限公司_files/Btn-unit-zerg-queen.png>)](https://starcraft.huijiwiki.com/wiki/%E5%90%88%E4%BD%9C%E4%BB%BB%E5%8A%A1/%E5%87%AF%E7%91%9E%E7%94%98/%E8%99%AB%E5%90%8E "合作任务/凯瑞甘/虫后")防御型单位。能使用孵化幼虫、产下菌毯肿瘤和哺液技能。在菌毯上的移动速度大幅提升。  
  
可以对地和对空。[虫后](https://starcraft.huijiwiki.com/wiki/%E5%90%88%E4%BD%9C%E4%BB%BB%E5%8A%A1/%E5%87%AF%E7%91%9E%E7%94%98/%E8%99%AB%E5%90%8E "合作任务/凯瑞甘/虫后") [![Btn-unit-zerg-hydralisk-lurker.png](<./凯瑞甘 Kerrigan - 星际争霸中文维基 - 灰机wiki - 北京嘉闻杰诺网络科技有限公司_files/Btn-unit-zerg-hydralisk-lurker.png>)](https://starcraft.huijiwiki.com/wiki/%E5%90%88%E4%BD%9C%E4%BB%BB%E5%8A%A1/%E5%87%AF%E7%91%9E%E7%94%98/%E5%88%BA%E8%9B%87 "合作任务/凯瑞甘/刺蛇")高伤害远程单位。可变异为潜伏者。  
  
可以对空和对地。

可以对地。

解锁于5级[潜伏者](https://starcraft.huijiwiki.com/wiki/%E5%90%88%E4%BD%9C%E4%BB%BB%E5%8A%A1/%E5%87%AF%E7%91%9E%E7%94%98/%E6%BD%9C%E4%BC%8F%E8%80%85 "合作任务/凯瑞甘/潜伏者") [![Btn-unit-zerg-mutalisk-broodlord.png](<./凯瑞甘 Kerrigan - 星际争霸中文维基 - 灰机wiki - 北京嘉闻杰诺网络科技有限公司_files/Btn-unit-zerg-mutalisk-broodlord.png>)](https://starcraft.huijiwiki.com/wiki/%E5%90%88%E4%BD%9C%E4%BB%BB%E5%8A%A1/%E5%87%AF%E7%91%9E%E7%94%98/%E5%BC%82%E9%BE%99 "合作任务/凯瑞甘/异龙")空中单位。能够利用弹射攻击同时伤害多个目标。可变异为巢虫领主。  
  
可以对地和对空。[异龙](https://starcraft.huijiwiki.com/wiki/%E5%90%88%E4%BD%9C%E4%BB%BB%E5%8A%A1/%E5%87%AF%E7%91%9E%E7%94%98/%E5%BC%82%E9%BE%99 "合作任务/凯瑞甘/异龙") [![Btn-unit-zerg-broodlord.png](<./凯瑞甘 Kerrigan - 星际争霸中文维基 - 灰机wiki - 北京嘉闻杰诺网络科技有限公司_files/Btn-unit-zerg-broodlord.png>)](https://starcraft.huijiwiki.com/wiki/%E5%90%88%E4%BD%9C%E4%BB%BB%E5%8A%A1/%E5%87%AF%E7%91%9E%E7%94%98/%E5%B7%A2%E8%99%AB%E9%A2%86%E4%B8%BB "合作任务/凯瑞甘/巢虫领主")大型飞行作战生物。通过投射出的巢虫来攻击目标。巢虫是一种可以对地的小型生物。

    -   实际散布周期是有升级和没升级效果的叠加，即10码内每0.75和0.375秒各传播1格菌毯，10码外每0.375秒传播1格菌毯
-   对于[![Btn-building-zerg-hatchery.png](<./凯瑞甘 Kerrigan - 星际争霸中文维基 - 灰机wiki - 北京嘉闻杰诺网络科技有限公司_files/Btn-building-zerg-hatchery.png>)](https://starcraft.huijiwiki.com/wiki/%E5%90%88%E4%BD%9C%E4%BB%BB%E5%8A%A1/%E5%87%AF%E7%91%9E%E7%94%98/%E5%AD%B5%E5%8C%96%E5%9C%BA "合作任务/凯瑞甘/孵化场")[孵化场](https://starcraft.huijiwiki.com/wiki/%E5%90%88%E4%BD%9C%E4%BB%BB%E5%8A%A1/%E5%87%AF%E7%91%9E%E7%94%98/%E5%AD%B5%E5%8C%96%E5%9C%BA "合作任务/凯瑞甘/孵化场")：散布周期：0.75→0.375

-   菌毯散布速度和范围、菌毯肿瘤视野提升均只对凯瑞甘的建筑有效
-   与战役版不同，回血和加攻速效果不影响建筑
-   星际争霸2中单位被装载时处于隐藏状态，位置则会被定期同步至装载单位中心位置
