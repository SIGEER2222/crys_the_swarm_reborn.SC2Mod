## 升级天赋

_![Talent-zagara-level01-relentless.png](<./扎加拉 Zagara - 星际争霸中文维基 - 灰机wiki - 北京嘉闻杰诺网络科技有限公司_files/Talent-zagara-level01-relentless.png>)_

1

无尽虫群 Relentless Swarmer

扎加拉的补给上限为100，但她的作战单位消耗更少的资源并可更快孵化。一次可孵化两只工蜂。虫后只占用1点人口补给。幼虫孵化速度提高。

备注：

资源消耗减少10%，孵化时间减少60%；孵化工蜂消耗的晶矿和时间增加50%；幼虫孵化间隔从15秒降低至10.5秒

_![Talent-zagara-level02-massroachdrop.png](<./扎加拉 Zagara - 星际争霸中文维基 - 灰机wiki - 北京嘉闻杰诺网络科技有限公司_files/Talent-zagara-level02-massroachdrop.png>)_

2

感染空投 Infested Drop

扎加拉可以在地图上的任何位置空投有限时生命的蟑螂。空投囊在着陆时会造成伤害。

_![Talent-zagara-level03-improvedinjectlarva.png](<./扎加拉 Zagara - 星际争霸中文维基 - 灰机wiki - 北京嘉闻杰诺网络科技有限公司_files/Talent-zagara-level03-improvedinjectlarva.png>)_

3

幼虫注射 Inject Larvae

虫后的孵化幼虫技能孵化的幼虫数量由4个提高到8个。

_![Talent-zagara-level04-scourgeresearchbundle.png](<./扎加拉 Zagara - 星际争霸中文维基 - 灰机wiki - 北京嘉闻杰诺网络科技有限公司_files/Talent-zagara-level04-scourgeresearchbundle.png>)_

4

爆蚊升级包 Scourge Upgrade Cache

在爆蚊巢穴中解锁新的研究项目：  

-   爆蚊死后会对小范围内造成相当于它们50%攻击力的伤害。
-   变异爆蚊所需的高能瓦斯数量减少50点。

_![Talent-zagara-level05-unlockbilelauncher.png](<./扎加拉 Zagara - 星际争霸中文维基 - 灰机wiki - 北京嘉闻杰诺网络科技有限公司_files/Talent-zagara-level05-unlockbilelauncher.png>)_

5

新单位：胆汁喷射体 New Unit: Bile Launcher

解锁将工蜂变异为胆汁喷射体的能力，这是一种可对地面和空中目标造成范围伤害的防御建筑。

_![Talent-kerrigan-level04-zerglingresearchbundle.png](<./扎加拉 Zagara - 星际争霸中文维基 - 灰机wiki - 北京嘉闻杰诺网络科技有限公司_files/Talent-kerrigan-level04-zerglingresearchbundle.png>)_

6

跳虫升级包 Zergling Upgrade Cache

在分裂池中解锁新的研究项目：  

-   跳虫最大生命值提高10点。
-   跳虫的攻击会使目标的护甲值降低到0，持续10秒。

_![Talent-zagara-level07-volatilebanelingnest.png](<./扎加拉 Zagara - 星际争霸中文维基 - 灰机wiki - 北京嘉闻杰诺网络科技有限公司_files/Talent-zagara-level07-volatilebanelingnest.png>)_

7

爆虫巢穴：哺育腔 Baneling Nest: Birthing Chamber

爆虫巢穴会周期性地孵化免费的爆虫。

_![Btn-upgrade-zerg-rupture.png](<./扎加拉 Zagara - 星际争霸中文维基 - 灰机wiki - 北京嘉闻杰诺网络科技有限公司_files/Btn-upgrade-zerg-rupture.png>)_

8

孕育爆虫和爆蚊 Incubate Banelings and Scourge

畸变体死亡时，它们的尸体上会孵化出2只爆虫。腐化者死亡时会孵化2只爆蚊。

_![Talent-zagara-level09-evolutionchamberresearchbundle.png](<./扎加拉 Zagara - 星际争霸中文维基 - 灰机wiki - 北京嘉闻杰诺网络科技有限公司_files/Talent-zagara-level09-evolutionchamberresearchbundle.png>)_
