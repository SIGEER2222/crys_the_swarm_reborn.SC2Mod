地嗪造就的天才   
Terrazine-Fueled Genius

艾贡·斯台特曼性格古怪偏执，时常产生各种由地嗪引起的幻觉，他曾是休伯利安号上的首席科学顾问。在遭受极端隔离和长期暴露在地嗪环境中后，斯台特曼的心智发生了巨大的变化，但他的思维仍然像以前一样敏锐，甚至更危险了。
