**投射能量场 (Ctrl + Z)  
Project Power Field**冷却时间：30秒  
  
在目标位置投射一个能量场。再次使用这个技能会将能量场移动到一个新的位置。你的盟友也能使用这个能量场。影响范围：6

**轨道轰炸 (Ctrl + X)  
Orbital Strike**冷却时间：30秒  
25  
从高空轨道向战场发射5束激光，每一束造成50(100 vs 重甲单位)点范围伤害。影响范围：1备注：

-   进入瞄准界面时即会消耗能量并进入冷却时间，一次未用便取消瞄准时返还能量和冷却时间

-   落地延迟0.75秒，期间获得目标区域视野

![Btn-ability-spearofadun-shieldovercharge.png](<./阿塔尼斯 Artanis - 星际争霸中文维基 - 灰机wiki - 北京嘉闻杰诺网络科技有限公司_files/Btn-ability-spearofadun-shieldovercharge.png>)

**护盾超载 (Ctrl + C)  
Shield Overcharge**初始冷却时间：180秒  
冷却时间：180秒  
50  
友方单位和建筑最多能吸收200点伤害，持续20秒。影响范围：全地图备注：

-   可以影响隐藏单位

-   还会回复所有受影响单位1点护盾值

![Btn-ability-spearofadun-solarbombardment.png](<./阿塔尼斯 Artanis - 星际争霸中文维基 - 灰机wiki - 北京嘉闻杰诺网络科技有限公司_files/Btn-ability-spearofadun-solarbombardment.png>)

**太阳轰炸 (Ctrl + V)  
Solar Bombardment**\- 解锁于等级10初始冷却时间：300秒  
冷却时间：300秒  
  
从亚顿之矛上发射400发随机攻击轰炸目标区域，持续15秒。每一发攻击造成15(30 vs 重甲单位)点范围伤害。影响范围：10备注：

-   每0.15秒产生4处随机位置轰炸，共计100波轰炸

-   由于触发器最小单位周期为0.0625秒，因此实际间隔是0.1875秒，总时间18.75秒

-   随机区域的半径会在轰炸期间从2逐渐线性增加到10

-   每发轰炸对1码范围造成100%伤害，对2码范围造成50%伤害

![Btn-ability-spearofadun-guardianshell.png](<./阿塔尼斯 Artanis - 星际争霸中文维基 - 灰机wiki - 北京嘉闻杰诺网络科技有限公司_files/Btn-ability-spearofadun-guardianshell.png>)

**守护之壳  
Guardian Shell**\- 解锁于等级2友方单位在5秒内获得无敌并免于死亡。还会恢复15%的生命值与护盾值。同一个单位每4分钟只能被保护一次。  
  
被动技能。备注：

-   无法影响建筑

-   先清空生命与护盾再恢复15%，因此被穿透护盾的伤害触发时可能会倒扣护盾值

-   无敌效果结束后开始计算冷却

![Btn-ability-spearofadun-warpharmonization.png](<./阿塔尼斯 Artanis - 星际争霸中文维基 - 灰机wiki - 北京嘉闻杰诺网络科技有限公司_files/Btn-ability-spearofadun-warpharmonization.png>)

**折跃谐振  
Warp Harmonization**\- 解锁于等级8折跃门研究影响星门和机械台，使它们能将单位折跃到任何有水晶能量场的位置。

显示有多少能量可以用来激活亚顿之矛的技能。

### 补充说明

基础能量上限为200，初始能量值为0，每秒恢复0.2812点能量值

-   即约需要12分钟可以回满能量
-   能量恢复速度是虚空之遗战役的一半
