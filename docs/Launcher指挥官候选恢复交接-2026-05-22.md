## 当前已知的最小阿巴瑟候选结构

```galaxy

```

循环逻辑是：

```galaxy
for ( ; lv_i <= gv_commanderNum ; lv_i += 1 )
```

## MPQEditor 使用要点

查看帮助：

```powershell
.\tools\mpq\mpqeditor\x64\MPQEditor.exe /console <script.txt>
```

`add` 命令帮助：

```text
a[dd] MpqFile [SourceFile] [TargetName] [/wav] [/c] [/auto] [/r]
```

`extract` 命令帮助：

```text
e[xtract] MpqFile FileName [TargetDir] [/listfile FileName] [/fp] [/lower] [/locale:LCID]
```

正确提取单文件示例：

```text
e tmp_Launcher_abathur_root.SC2Map MapScript.galaxy tmp_verify_abathur_root /fp
e tmp_Launcher_abathur_root.SC2Map Base.SC2Data\GameData\UserData.xml tmp_verify_abathur_root /fp
e tmp_Launcher_abathur_root.SC2Map zhCN.SC2Data\LocalizedData\GameStrings.txt tmp_verify_abathur_root /fp
x
```

注意：`extract` 每行都要带 MPQ 文件名，不能只 `open` 后省略 MPQ 名。

## 已踩过的打包坑

### 坑 1：TargetName 写成 `*` 会把文件打到错误目录

错误命令：

```text
a tmp_Launcher_abathur.SC2Map tools\launcher_mpq\* * /r
```

结果：MPQ 内部路径变成：

```text
*\Base.SC2Data\GameData\UserData.xml
*\zhCN.SC2Data\LocalizedData\GameStrings.txt
*\MapScript.galaxy
```

这会导致 SC2 找不到根目录下的：

```text
MapScript.galaxy
Base.SC2Data/GameData/UserData.xml
```

这个包不能用。

### 坑 2：中文路径下 MPQEditor 输出信息会乱码

这不一定代表失败，但会影响判断。

建议使用：

```text
仓库内已有 tools/launcher_mpq 作为源
临时验证目录用简单英文名
必要时用 $env:TEMP 下的 ASCII 子目录
```

### 坑 3：工具对 E 盘游戏目录有权限限制

当前工具环境允许读 E 盘，但很多写操作会被拦截，例如：

```text
Copy-Item 到 E:\SC2\...
Remove-Item E:\SC2\...
```

因此对游戏目录的最终替换，必要时让用户手动复制，或者使用已有可执行同步脚本/robocopy 方式。
