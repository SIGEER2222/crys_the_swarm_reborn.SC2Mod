# 阿巴瑟后续改动方案

## 1. 宿主这次改动的性质

结论：
- 这次给宿主、爆虫宿主、黄蜂宿主加的，不是新的数值效果。
- 我加的是“购买入口”，让它们能点到模组里原本就存在的宿主系升级。

对应的现成升级是：
- `HotSRapidIncubation`
- `HotSLocustSpeed`
- `HotSPressurizedGlands`

也就是说：
- `快速孵化`、`蝗虫速度`、`加压腺体` 这些效果本身，模组里原来就有。
- 之前缺的是宿主系单位身上没有统一、直接可点的购买入口。
- 这次补的是一个共享研究入口 `SwarmHostResearch`，不是新造了一套独立效果。

## 2. 关于“已购买后变灰”

你说得对。

当前模组常见的逻辑本来就是：
- 买过之后按钮置灰，或
- 买过之后只显示被动图标，不再给购买按钮。

所以严格说：
- “防重复购买”的判断本身不是为了加前置科技。
- 它只是用来防止已经买过的升级再次被购买。

目前宿主那次改动里我采用的是：
- 研究按钮 + 已研究后显示结果图标

如果后面统一风格，可以改成下面两种之一：

方案 A：
- 保持现在这种
- 没买时显示可购买按钮
- 买完后显示对应被动图标

方案 B：
- 完全照你说的已有逻辑
- 没买时按钮可点
- 买完后同一个按钮变灰
- 不额外切换成另一套显示方式

## 3. 宿主这次改动像不像“四选一”

不像真正的“四选一”进化界面。

更准确地说，它是：
- 同兵种系共用一套升级
- 每个升级都可以单独买
- 不是互斥关系
- 不是四选一分支

只有下面这种情况才像“四选一”：
- 同一兵种只能在几个升级里选一个
- 选了 A 就不能再选 B、C、D

而我现在给宿主系做的是：
- `快速孵化`
- `蝗虫速度`
- `加压腺体`

这 3 个都能买，不互斥，所以它更像“同兵种系共享升级栏”，不是“进化四选一”。
