# 阿巴瑟兵种可购买科技核查

时间：2026-05-20

数据基准：
- `crys_the_swarm_reborn.SC2Mod/Base.SC2Data/GameData/UnitData.xml`
- `crys_the_swarm_reborn.SC2Mod/Base.SC2Data/GameData/AbilData.xml`

判定口径：
- `有可购买科技`：单位卡上直接挂了可点击的购买按钮。
- `仅共享/仅被动显示`：单位身上只显示继承被动、旧突变页被动，或共享体系结果，但当前单位自己没有购买入口。
- `未见购买链`：当前单位既没有明确购买按钮，也没看到成体系的购买链挂载。

## 结论

按“单位自己能不能在卡片里直接购买科技”这个标准，阿巴瑟**还没有全覆盖**。

目前比较完整的是：
- 王虫系
- 刺蛇系主入口
- 法术兵系
- 莽兽/王兽系

目前还明显缺口的是：
- 宿主系
- 高级空军系
- 穿刺者 / 潜伏者
- 利维坦
- 部分异龙分支
- 部分爆虫、蟑螂衍生分支

## 备注

- 这份核查是按“单位卡里是否能直接花矿/气购买”来算。
- 如果某个单位只是继承了同系共享结果，但自己不能点购买，这里仍然不算“已有可购买科技”。
- 所以如果目标是“阿巴瑟每个主要兵种都能自己买科技”，那当前还差的重点就是：
  - 宿主系
  - 高级空军系
  - 穿刺者 / 潜伏者
  - 利维坦
