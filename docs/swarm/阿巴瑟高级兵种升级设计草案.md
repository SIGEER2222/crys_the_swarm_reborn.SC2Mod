# 阿巴瑟高级兵种升级设计草案

生效目标目录：
`E:\SC2\SC2new\StarCraft II\Mods\crys_the_swarm_reborn.SC2Mod`

## 设计原则

- 不再按“名字像同系”强行并组，而是按实际攻击方式、战斗定位、是否依赖召唤物来设计。
- `穿刺者`、`潜伏者` 不并入普通刺蛇升级线。
- `巢虫领主` 视为“发射巢虫的高级空军”，优先强化巢虫数量、巢虫生存、攻击节奏。
- `吞噬者` 视为“压制型对空重单位”，优先强化射程、压制效率、伤害。
- `莽兽` 视为“重型突击巨兽”，单独做耐久与压制能力。

## 当前数据观察

### 1. 吞噬者 / 巢虫领主

模组里已经有一套现成的高级空军共享科技文本与被动显示：

- `全视之眼`
  - 巢虫领主、守护者、克拉肯攻击范围 +2
  - 吞噬者对空攻击范围 +3
- `毁灭者`
  - 巢虫领主每次攻击固定孵化 2 只巢虫
  - 吞噬者和克拉肯伤害 +33%
- `战术功效`
  - 巢虫生命值 +30
  - 吞噬者削弱敌方攻速与护甲的效率翻倍

结论：
- 这组不需要新造一套名字。
- 更合理的做法是：继续把 `吞噬者`、`巢虫领主` 归到这条高级空军共享线里。
- 如果阿巴瑟当前缺的是“购买入口”，那就补入口，不重做效果。

### 2. 穿刺者

当前定位：

- 超远距离
- 对地
- 偏单体爆发
- 对重甲特化
- 潜地后可缓慢移动，菌毯上更快

结论：
- 它的核心不是“刺蛇站撸输出”
- 而是“重甲点杀 + 潜地机动”
- 所以应该独立成一条小线

### 3. 潜伏者

当前定位：

- 对地直线穿刺
- 伏击型输出
- 潜地移动
- 更偏清线、穿透和阵地压制

结论：
- 它的核心不是普通刺蛇的对空/通用远程
- 而是“潜地直线火力”
- 也应该独立成一条小线

### 4. 莽兽

当前定位：

- 大体型重突击单位
- 地空都能打
- 适合做冲阵和吃伤害

结论：
- 不建议并到雷兽共享线里直接糊过去
- 更适合单独做“生存 / 溅射 / 追击”三方向

## 建议分组

### A 组：高级空军共享线

包含：

- 吞噬者
- 巢虫领主
- 守护者
- 克拉肯

采用现成三项，不改名字：

1. `全视之眼`
   - 价格：`25/25`
   - 作用重点：
   - 巢虫领主吃射程
   - 吞噬者吃对空压制距离

2. `毁灭者`
   - 价格：`50/50`
   - 作用重点：
   - 巢虫领主固定 2 巢虫
   - 吞噬者伤害提高

3. `战术功效`
   - 价格：`25/25`
   - 作用重点：
   - 巢虫血量 +30
   - 吞噬者减甲/减攻速效率翻倍

备注：
- 这组建议优先检查“阿巴瑟是否缺购买入口”
- 如果只是入口缺失，就补入口，不重写效果

### B 组：穿刺者独立线

包含：

- 穿刺者

建议三项：

1. `穿刺脊针`
   - 价格：`25/25`
   - 效果：对重甲额外伤害提高
   - 说明：模组里已有同名效果痕迹，优先复用

2. `潜地机动`
   - 价格：`25/25`
   - 效果：潜地移动速度提高，菌毯上额外再提一档
   - 说明：贴合穿刺者“潜地缓慢推进”的实际玩法

3. `超距突刺`
   - 价格：`50/50`
   - 效果：攻击距离 +1，或索敌距离 +1
   - 说明：强化超远程点杀定位

### C 组：潜伏者独立线

包含：

- 潜伏者

建议三项：

1. `裂地棘线`
   - 价格：`25/25`
   - 效果：直线攻击伤害 +1，或线段长度/有效宽度增强
   - 说明：优先强化清线和贯穿

2. `潜猎滑行`
   - 价格：`25/25`
   - 效果：潜地移动速度提高
   - 说明：这是潜伏者手感最直接的一项

3. `伏击腺体`
   - 价格：`50/50`
   - 效果：出手节奏强化
   - 可实现方向：
   - 攻速提高
   - 首次攻击更快
   - 潜地攻击前摇缩短

### D 组：莽兽独立线

包含：

- 莽兽

建议三项：

1. `践踏甲壳`
   - 价格：`50/50`
   - 效果：生命值 / 护甲 / 受伤恢复增强

2. `狂暴撕裂`
   - 价格：`50/50`
   - 效果：主攻伤害或溅射能力提高

3. `巨兽再生`
   - 价格：`25/25`
   - 效果：战斗中持续回血，或击杀后回复生命

## 建议执行顺序

第一步：
- 先查清 `吞噬者 / 巢虫领主` 这一组是不是“效果已存在，只缺购买入口”

第二步：
- 先做 `穿刺者` 独立线

第三步：
- 再做 `潜伏者` 独立线

第四步：
- 最后做 `莽兽`

## 当前结论

最重要的改动方向是：

- `吞噬者 + 巢虫领主` 继续走高级空军共享系
- `穿刺者` 单独做
- `潜伏者` 单独做
- `莽兽` 单独做

这样最贴近当前兵种实际，不会出现“兵种打法和升级效果对不上”的问题。
