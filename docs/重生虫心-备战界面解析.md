来源：`Lib48DF4533.galaxy` 的 `Unity / Evolutions / Mutations` 触发逻辑，结合 `zhCN GameStrings.txt` 的中文标题与说明。

说明：
- 这里的“n选1”以实际 `BankValueSetFromString(...)` 逻辑为准。
- `内部值` 是存档/触发器里真正写入的英文值，后续改逻辑时很有用。
- `简述` 为界面 tooltip 的中文内容做了轻度清洗，保留了原意。

## 进化页

### 跳虫系

1. `腾跃虫`
内部值：`Raptorling`
简述：腾跃虫变种跳虫伤害+2，移速提升，可跳跃攻击敌人或跨越悬崖。
2. `裂变虫`
内部值：`Swarmling`
简述：裂变虫孵化更快，每卵孵化3只，人口消耗从0.5降至0.33
3. `幼雷兽`
内部值：`Pygalisk`
简述：幼雷兽是跳虫的精英替代品，拥有卓越的生存能力和溅射伤害，但需要消耗瓦斯。
4. `恶毒虫`
内部值：`Toxic`
简述：爆虫会增加敌人受到的伤害，其他属性与普通跳虫相同。

### 爆虫系

1. `猎杀虫`
内部值：`Hunter`

2. `分裂虫`

简述：死亡时分裂为两个小型个体，每个造成减额伤害。
3. `霜煞兽`
内部值：`Frost Fiend`
简述：霜煞兽向敌人喷射冰晶碎片，对近距离的地空单位造成持续伤害。

内部值：`Bile Titan`
简述：巨型攻城单位，胆汁泰坦拥有高生命值，可对建筑和轻型单位造成持续巨额伤害

简述：破坏者比普通蟑螂攻速更快、射程更远，但造价更高。腐蚀胆汁提供范围伤害并可自动施放。

简述：刺蛇现在对轻甲单位造成额外伤害，并可变异为潜伏者。潜伏者能对地面轻型单位造成贯穿直线的强力伤害，可在埋地状态下缓慢移动，且在菌毯上移动更快。

内部值：`Impaler`
简述：刺蛇对重甲单位造成额外伤害，可进化为穿刺者。穿刺者能从超远距离对地面重甲单位造成巨额单体伤害，埋地时可缓慢移动（菌毯上加速）。
3. `屠猎者`
内部值：`Hunter-Killer`
简述：屠猎者是刺蛇的精英版本，拥有极高的伤害和射程，其造价远高于普通刺蛇。
4. `恶毒变种`
