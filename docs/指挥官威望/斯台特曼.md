# 斯台特曼 (Egon Stetmann)

## 威望1：盖瑞强化

**推荐度**：⭐⭐⭐（一般）

**效果**：
- **盖瑞属性大幅提升**
- **盖瑞获得额外技能**

**详细效果**：
- 盖瑞：伤害和技能大幅强化
- 盖瑞：可以在战场快速移动
- 其他单位：属性降低

**详细效果**：
- 盖瑞：能力大幅提升
- 机械狗：无法建造

**实战评价**：
推荐度一般，估计只有对抗软和蜕变等克制艾星的因子时有机会出场。总体而言失去晁盖对疯子来说是削弱。

## 威望2：生态强化（最强五大威望之一）

**推荐度**：⭐⭐⭐⭐⭐（极高）

**效果**：
- **资源采集效率提升**
- **科技研发速度加快**
- **单位生产速度提升**

**详细效果**：
- 资源采集：效率大幅提升
- 科技研发：速度加快
- 单位生产：速度提升
- 机械单位：属性提升

**详细效果**：
- 经济：全面强化
- 科技：研发速度加快
- 盖瑞：无法使用进攻技能

**实战评价**：
最强的五大威望之一。这个威望强大到让疯子变成了全游戏最不好玩的指挥官。本身疯子就是天梯Z套了一群极其无脑的数值和黑科技的指挥官，玩法几乎就是天梯的改版，很缺乏乐趣性。而v2晁盖无双的出现更是让疯子的打法变得更加索然无味，颇有一种无敌是多么寂寞的感觉。

---

## 威望3：机械单位强化

**推荐度**：⭐⭐⭐⭐（较高）

**效果**：
- **机械单位属性提升**
- **机械单位成本降低**
- **机械单位生产速度提升**

**详细效果**：
- 机械单位：成本降低
- 机械单位：属性提升
- 机械单位：生产速度提升
- 机械单位死亡：产生额外小机械单位

**详细效果**：
- 机械海：大幅强化
- 有机单位：无法建造
- 盖瑞：无法使用恢复技能

**实战评价**：
推荐度高，越用发现越有用的威望。也是疯子娱乐性最好的威望。这个威望很多人不清楚具体适用的场合因此觉得它很垃圾，其实这是个单位特化威望。当出现大量僵尸和巢虫时这个威望强度高的可怕。也就是说，当玩两张僵尸图和双出时，你可以毫不犹豫地选择这个威望。
