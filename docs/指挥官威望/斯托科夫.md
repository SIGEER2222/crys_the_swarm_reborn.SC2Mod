# 斯托科夫 (Alexei Stukov)

## 威望1：地堡强化

**推荐度**：⭐⭐⭐⭐（较高）

**效果**：
- **被感染的地堡孵化被感染的士兵的速度提高**
- **被感染的地堡没有装载容量**
- **失去建造被感染的移民营的能力**

**详细效果**：
- 孵化速度：大幅提升百分比
- 装载容量：无上限
- 移民营：无法建造

**实战评价**：
其实是毛子最强的威望，但是由于非常需要操作导致玩的人很少。毛子机械化最大的问题就在于昂贵，而v1基本解决了这个问题。另外移民营在软、蜕变和吸血存在的情况下完全是个内鬼，因此没了移民营反而提高了毛子对这三个因子的抗性。

## 威望2：机械单位强化

**推荐度**：⭐⭐（较低）

**效果**：
- **机械单位强化**
- **战列巡洋舰亚历山大号可部署**

**详细效果**：
- 战列巡洋舰：可部署，拥有强大技能
- 机械单位：属性强化

**实战评价**：
可以用来测试显卡或者恶心你看不爽的队友。

---

## 威望3：战列巡洋舰强化

**推荐度**：⭐⭐⭐⭐⭐（极高）

**效果**：
- **亚历山大号战列巡洋舰强化**
- **战列巡洋舰可以持续产生被感染的士兵**

**详细效果**：
- 亚历山大号：属性大幅提升
- 被感染士兵：持续产出
- 机械单位：无法建造

**实战评价**：
毛子出场率最高的威望。其实强度说很高吧倒也说不上，主要是省力省心而且加强了毛子的长板。另外即使玩这个威望也要出点坦克，并不建议一股脑把地堡按满。
