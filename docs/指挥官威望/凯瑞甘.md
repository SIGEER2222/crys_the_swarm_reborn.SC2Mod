# 凯瑞甘 (Sarah Kerrigan)

## 威望1：恶毒族长

**推荐度**：⭐⭐（较低）

**效果**：
- **虫后走出菌毯不再减少移动速度**
- **菌毯肿瘤可以被虫后随意铺设在没有菌毯的地面上**
- **恶变菌毯效果提升100%**：
  - 恶变菌毯蔓延范围从13格增加到15格
  - 恶变菌毯完全覆盖时间从90秒减少到60秒
  - 菌毯肿瘤视野范围从13格增加到15格
  - 恶变菌毯攻击速度加成从30%增加到60%
  - 恶变菌毯生命恢复速度从1点增加到2点
- **无法直接建造奥米茄坑道虫**（但如果队友是阿巴瑟，他可以正常建造奥米茄坑道虫）

**实战评价**：
对空军毫无加成，但对地面友军的加成却非常大，特别是阿巴瑟和斯托科夫非常喜欢。但是这加成对自己来说其实并没有卵用，额外的30%攻速并不能带来质变，而回血加成除非你想纯狗刺蛇打黑死。

## 威望2：人类的愚行

**推荐度**：⭐⭐⭐⭐⭐（极高）

**效果**：
- **跳击与灵能位移会消耗狂怒层数来释放群体闪电**，对最远9格半径内的敌人造成50点法伤，并且昏迷普通敌人3秒
  - 1层狂怒：1道闪电
  - 2层狂怒：2道闪电（共3道）
  - 3层狂怒：3道闪电（共6道）
  - 4层狂怒：6道闪电（共12道）
  - 5层狂怒：12道闪电（共24道）
- **狂怒**：每次普通攻击加1层，上限5层，每层增加10%攻速
- **变异甲壳获取量减少50%，上限200点不变**
- **技能伤害降低50%**（跳击150→195，精通195；灵能位移50→65，精通65；定身波50→100，精通100）

**详细数据**：
- 攻速精通30%+菌毯：308帧=3.2秒出5层狂怒
- 攻速精通30%+无菌毯：380帧=3.9秒
- 无精通+菌毯：380帧=3.9秒
- 无精通+无菌毯：504帧=5.2秒

**实战评价**：
凯瑞甘的主战威望，闪电链这个效果谁用谁真香，大范围AOE群控给予了凯瑞甘的部队更好的输出环境，完全可以弥补技能伤害减半的负面效果，甚至一定程度上缓解了凯瑞甘对空的劣势。

## 威望3：荒寂女王

**推荐度**：⭐⭐⭐⭐（较高）

**效果**：
- **吸收光环效率提升100%，凯瑞甘游戏模型换成虫心战役的人类幽灵模型**
- **"跳击"被替换成"动能冲击"**：50能量（升级科技40能量），法伤300（精通390），可对空、对地
- **"灵能位移"替换为"粉碎勒握"**：75能量（升级科技60能量），法伤50（精通65），持续5秒浮空抓取，对英雄造成持续5秒减少50%攻速、减少50%移速效果，可对空、对地、无视隐身强制抓取破隐
- **吸收光环采集量翻倍**

**吸收光环采集效率表**：
- 0：感染枪兵、巢虫、蝗虫、眼虫、蜘蛛雷
- 10：爆蚊、爆虫、狗、王虫
- 20：三族农民、枪兵、死神
- 40：混合体、先知、侦察机、火蟑螂、畸变体、宿主、地刺、飞蛇、坦克、导弹车、女妖、解放
- 80：追猎、不朽、自爆球、白球、虚空、仲裁、风暴、大龙
- 100：雷兽、金甲、巨像、航母、雷神、大和、所有任务目标

**实战评价**：
削弱了凯瑞甘本体的机动性换取更好的经济能力和狙杀高危单位的能力，这个威望也可以考虑常驻。
