# 扎加拉 (Zagara)

## 威望1：爆虫专家

**推荐度**：⭐⭐⭐⭐（较高）

**效果**：
- **额外孵化爆虫**
- **额外孵化跳虫**

**详细效果**：
- 额外孵化一定数量的爆虫
- 额外孵化1只跳虫
- 额外孵化1只爆蚊

**实战评价**：
在对抗如杀戮机器人等需要高额产能的场合效果不错。这个威望提供了优秀的产能加成，适合需要大量单位的场合。

---

## 威望2：畸变体强化

**推荐度**：⭐⭐（较低）

**效果**：
- **群体狂暴只会影响扎加拉和她的召唤单位**
- 畸变体和腐化得到的增益不低

**详细效果**：
- 群体狂暴效果改变：只影响扎加拉本体和召唤单位
- 畸变体获得强化
- 腐化获得强化

**实战评价**：
其实畸变体和腐化得到的增益不低，负面效果也不算砍到命根子上，奈何畸变体和腐化与扎加拉的作战体系格格不入。

---

## 威望3：最大补给150

**推荐度**：⭐⭐⭐⭐⭐（极高）

**效果**：
- **扎加拉的最大补给数提高到150**
- 扎加拉的爆蚊巢穴数量限制为1个
- 额外孵化1只爆蚊
- 额外孵化1只跳虫

**详细效果**：
- 补给上限：100 → 150（+50%）
- 爆蚊巢穴限制：多个 → 1个
- 每次孵化额外产出：+1跳虫/+1爆蚊

**实战评价**：
扎加拉的主战威望。不要以为部队涨价很痛，扎加拉的RPG能力完全可以弥补这一缺陷。这个威望给予了扎加拉非常强大的控图能力和阵地推进能力，使得炸鸡在部分高能场合也有一战之力。
