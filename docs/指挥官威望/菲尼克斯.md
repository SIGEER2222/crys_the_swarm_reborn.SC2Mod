# 菲尼克斯 (Fenix)

## 威望1：套装交换强化（原始净化者）

**推荐度**：⭐⭐⭐（一般）

**效果**：
- **套装交换技能强化**
- **造成的伤害提高50%**
- **冷却时间缩短50%**
- **储能期间生命值、护盾和能量恢复速度增加100%**

**详细效果**：
- 套装交换：伤害+50%，冷却-50%
- 储能期间：生命/护盾/能量恢复+100%
- 持续时间：延长至一定秒数

**详细效果**：
- 菲尼克斯套装交换：伤害提升50%，冷却缩短50%
- 储能期间：生命、护盾、能量恢复增加100%
- 持续时间：延长

**实战评价**：
俗称原始净化者，算德哈卡v2的青春版，使得菲鸡从一个平平无奇的前期英雄单位变成了杀伤力极大的面板，使菲鸡拥有了不错的白嫖能力。这个威望其实是菲鸡因子抗性最高的威望，但是常驻的人很少小。

## 威望2：净化者军团

**推荐度**：⭐⭐⭐⭐（较高）

**效果**：
- **所有净化者单位造价降低**
- **净化者单位属性提升**
- **无法使用套装交换终极技能**

**详细效果**：
- 净化者单位：成本大幅降低
- 单位属性：全面强化
- 套装交换：冷却时间增加

**实战评价**：
你可以把这个威望称为净化者大富翁。菲鸡v1出场率较低的罪魁祸首。v2的菲鸡部队造价相当便宜，是全游戏最合格的战损指挥官。无论埃蒙来什么因子都能依靠强换战损的方式打一打。

---

## 威望3：Avenger协议

**推荐度**：⭐⭐⭐（一般）

**效果**：
- **Avenger协议强化**
- **单位死亡时有几率返还**

**详细效果**：
- Avenger协议：大幅强化
- 死亡返还：有一定几率返还资源或单位

**实战评价**：
其实是有用的，但是很尴尬，因为这个威望更像是v2的青春版。现在只有在很特殊的情况下才能看见这个威望。一般如果你不是很想专精菲鸡的话这个威望就没必要练了。
