# 蒙斯克 (Arcturus Mengsk)

## 威望1：皇家卫队强化

**推荐度**：⭐⭐⭐⭐⭐（极高）

**效果**：
- **皇家卫队属性大幅提升**
- **帝国权威增长速度降低**

**详细效果**：
- 皇家卫队：属性大幅提升
- 皇家卫队：技能冷却缩短
- 帝国权威：增长速度降低

**详细效果**：
- 皇家卫队：攻速、技能全面强化
- 冲锋队：无法征召

**实战评价**：
v1使得大帝拥有了全游戏仅次于沃拉尊的控制能力。在部分双打情况下效果非常良好，不过并不适合常驻，因为核弹天劫毕竟是全游戏最强大的大招面板。

## 威望2：帝国精英

**推荐度**：⭐⭐（较低）

**效果**：
- **冲锋队属性提升**
- **帝国权威增长速度提升**

**详细效果**：
- 冲锋队：属性和产能提升
- 皇家卫队：成本提高，属性降低

**实战评价**：
其实皇家马戏团单看数值并不差劲，但是对于经验的需求度实在太高。而且即使成型了也基本被法國大炮、辐射打击和核弹天劫爆出屎来。

---

## 威望3：空军强化

**推荐度**：⭐⭐⭐⭐⭐（极高）

**效果**：
- **轰炸机和战列巡航舰属性提升**
- **帝国权威主要来源变为空中击杀**

**详细效果**：
- 轰炸机：效果强化
- 幽灵战机：属性提升
- 战列巡航舰：属性提升
- 地面单位：成本提高

**详细效果**：
- 轰炸机：产生额外轰炸效果
- 帝国权威：主要来源改变为空军击杀
- 地堡：无法建造

**实战评价**：
最强的五大威望之一，同时也是三大无负面威望之一。把蒙斯克从一个强度适中的指挥官拉到最强那一档的威望。蒙斯克作为防守指挥官最大的问题就在于前期防守成本太高，而v3的出现直接解决了这一情况。另外，即使蒙斯克的刁民无法守住阵线，还可以依靠自爆这一亡语效果以一换多，属于是一个稳赚不亏的效果。
