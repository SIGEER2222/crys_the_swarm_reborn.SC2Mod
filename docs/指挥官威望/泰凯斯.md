# 泰凯斯 (Tychus Findlay)

## 威望1：维嘉强化（维嘉宝可梦）

**推荐度**：⭐⭐⭐⭐（较高）

**效果**：
- **泰凯斯伤害提升**
- **泰凯斯受到的伤害降低**

**详细效果**：
- 泰凯斯：造成的伤害提高，受到的伤害降低
- 泰凯斯：可以独自作战
- 泰凯斯：获得特殊强化

**详细效果**：
- 泰凯斯单体：伤害大幅提升
- 泰凯斯单体：减伤效果
- 终极技能：被锁定

**实战评价**：
主要是玩维嘉宝可梦很舒服。这个威望让泰凯斯可以独自作战，在需要单独处理某些任务时非常有用。

## 威望2：全员强化

**推荐度**：⭐⭐⭐⭐⭐（极高）

**效果**：
- **所有不法之徒属性大幅提升**
- **不法之徒部署速度加快**

**详细效果**：
- 不法之徒：属性全面强化
- 不法之徒：技能冷却缩短
- 不法之徒：部署速度加快
- 泰凯斯：属性略微降低

**详细效果**：
- 所有不法之徒：伤害、技能、速度全面强化
- 不法之徒成本：略微提高
- 泰凯斯：个人能力降低

**实战评价**：
最强的五大威望之一，泰凯斯的主战威望。关于这个威望有多强我相信只要是玩泰凯斯的人都深有体会。

---

## 威望3：终极强化（买椟还珠）

**推荐度**：⭐⭐⭐（一般）

**效果**：
- **终极装甲强化**
- **装备系统强化**

**详细效果**：
- 终极装甲：属性大幅提升
- 装备：可以升级额外装备
- 装备成本：降低

**详细效果**：
- 装备系统：可以升级更多装备
- 装备成本：降低
- 不法之徒基础属性：降低

**实战评价**：
一句话概括：买椟还珠。这个威望改变了泰凯斯的玩法，但可能不是最优选择。
