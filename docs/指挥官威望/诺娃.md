# 诺娃 (Nova Terra)

## 威望1：隐形强化

**推荐度**：⭐⭐⭐⭐⭐（极高）

**效果**：
- **诺娃在隐形时无法被侦测到**
- **攻击或使用狙击会使诺娃的隐形效果消失一定秒数**

**详细效果**：
- 隐形等级：最高级别，无法被侦测
- 破隐惩罚：攻击或使用狙击后隐形消失一定时间

**详细效果**：
- 诺娃可以永久隐形
- 诺娃的永久隐形被打破时，会造成范围伤害并使附近敌人短暂眩晕
- 诺娃的隐形被打破后，恢复隐形的时间缩短

**实战评价**：
诺娃的主战威望。最后一个被补丁大幅加强的威望。诺娃凭借这个威望从中出女变成了末改女。诺娃原版最大的问题就在于主战兵种解放和渡鸦的产能不足，而这一威望完全解决了这个问题。

## 威望2：解放强化

**推荐度**：⭐⭐（较低）

**效果**：
- **解放者的属性强化**
- **核弹效果范围扩大**

**详细效果**：
- 解放者：属性大幅提升
- 核弹：效果范围增加百分比

**实战评价**：
如果你想模仿常凯申亲身体验一下军事物流学可以在MM图玩这个威望。

---

## 威望3：狙击强化

**推荐度**：⭐⭐⭐（一般）

**效果**：
- **狙击技能强化**
- **多个终极技能被锁定**

**详细效果**：
- 狙击：伤害和效果大幅提升
- 锁定技能：突击模式、狮鹫号空袭、全息诱饵、研究狱火爆弹、随机应变

**实战评价**：
其实这个威望最厉害的地方在于无人机和核弹的杀伤力大幅提高。但是问题在于喷子是诺娃最主要的对地AOE手段，失去了该形态使得诺娃的对地能力大幅下降。
