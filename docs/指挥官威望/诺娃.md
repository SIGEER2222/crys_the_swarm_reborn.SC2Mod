# 诺娃 (Nova Terra)

## 威望1：潜行者 (Covert Ops)

**效果：**
- 诺娃可以永久隐形
- 诺娃的永久隐形被打破时，会造成范围伤害并使附近敌人短暂眩晕
- 诺娃的隐形被打破后，恢复隐形的时间缩短
- 你的单位无法使用战术空运
- 格里芬号的冷却时间增加

**特点：**
- 强化了诺娃的个人潜行能力
- 打破隐形时还会造成伤害和眩晕
- 失去了战术空运

---

## 威望2：精英部队 (Elite Specialist)

**效果：**
- 你的精英单位的伤害、攻击速度、生命值和护盾都获得大幅提升
- 你的精英单位的能量恢复速度提高
- 你可以更快地部署精英单位
- 你的精英单位的成本提高
- 你无法建造普通单位，只能建造精英单位

**特点：**
- 精英单位获得极大强化
- 只能使用精英单位
- 成本增加需要更谨慎的选择

---

## 威望3：空袭指挥官 (Airstrike Commander)

**效果：**
- 你使用的所有格里芬号的技能冷却时间大幅缩短
- 你的格里芬号技能的效果获得强化
- 诺娃的战术召唤技能的冷却时间缩短
- 诺娃的战术召唤技能的效果强化
- 你的战斗单位的成本提高

**特点：**
- 聚焦于格里芬号空袭技能的运用
- 空袭技能使用频率大幅提升
- 战斗单位成本增加
