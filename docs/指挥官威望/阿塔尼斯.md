# 阿塔尼斯 (Artanis)

## 威望1：达拉姆的大主教（勇敢激励者）

**推荐度**：⭐⭐⭐（一般）

**效果**：
- **战斗单位资源消耗增加30%**
  - 叉子：130矿
  - 龙骑：163矿、65气
  - 不朽：325矿、130气
  - 金甲：390矿、260气
  - 电兵：65矿、195气
  - 凤凰：195矿、130气
  - 风暴：390矿、260气
- **所有战斗单位的主动技能效果提升100%**
  - 威望的降低技能50%冷却时间效果，与精通降低45%冷却乘法叠加到降低77.5%冷却

**详细技能强化**：
- 叉子（冲锋）：速度加快
- 旋风：3秒转7次法术伤害每次10点
- 反馈：每点能量造成2点伤害
- 闪电：冷却4秒，伤害160，恢复100盾
- 合球：速度加快12秒→6秒
- 不朽：冷却60秒，400盾
- 风暴：衰变冷却90秒→持续20秒造成1000点法术伤害
- 掠夺：金甲虫制造8秒→4秒一颗
- 凤凰：抬冷却15秒

**实战评价**：
大主教一贯特色的天赋，给谁都非常强，偏偏给了大主教。目前测试吃buff最强的三个单位是电兵、凤凰、金甲，最强龙骑没技能反而完全不吃buff成了最弱。

## 威望2：星灵使节

**推荐度**：⭐⭐⭐（一般）

**效果**：
- **投射能量场CD变成1秒**
- **再次使用能量场会把能量场内的单位传送到新的位置**
- **每次使用能量场投射都会触发大主教鸡血精通**（持续30秒，60%攻速、60%移动、60%冷却）
- **每次使用投射能量场都会消耗25点能量**

**详细数据**：
亚顿之矛回蓝是固定每秒0.28，所以回复25能量需要90秒的时间，相当于CD60秒的手电筒被砍到了90秒。

**实战评价**：
唯一一个在威望时代被砍到不能用的威望，曾经是大主教最强大的威望，如今却基本上没人会用。算是一个地图特化威望，在两张柱子图上表现还算可以。

## 威望3：亚顿之矛（投射能量场强化）

**推荐度**：⭐⭐⭐⭐⭐（极高）

**效果**：
- **开场送一个能量场放在基地旁边**
- **投射能量场变为可传送**
- 所有战斗单位的主动技能效果大幅提升

**实战评价**：
推荐度高但是同样不适合常驻的威望。土豆（阿塔尼斯）的输出能力其实非常恐怖，尤其是对上虫族AI时，可以撂翻不带正面因子的T7红点。失去守护之壳使得大主教的容错率和辅助能力大幅降低，但是这个威望起码提高了大主教的前期能力和AOE输出能力，还是可圈可点的。
