# 阿拉纳克 (Alarak)

## 威望1：晋升者强化

**推荐度**：⭐⭐⭐（一般）

**效果**：
- **晋升者属性强化**
- **灵魂收集效果提升**
- **技能伤害降低50%**

**详细效果**：
- 晋升者：攻击速度和伤害提升
- 灵魂收集：每收集一个灵魂，攻击速度和伤害提升
- 技能效果：大幅削弱

**实战评价**：
一个特化威望。坚果的技能伤害减半约等于将坚果本就不够强势的前期对半砍。而且要命的是由于需要死徒死亡机械单位才能吃到buff，导致晋升多少还是得出一点。不过在部分双打情况下后期效果还算不错。

## 威望2：献祭强化

**推荐度**：⭐⭐⭐⭐（较高）

**效果**：
- **献祭技能冷却时间减半**
- **晋升者可以将其吸收的部分伤害传递给阿拉纳克**

**详细效果**：
- 献祭冷却：减少50%
- 晋升者：伤害传递机制
- 晋升者能量恢复速度提升

**实战评价**：
火车图或者单正面无多线情况下好用的一个威望。由于供奉CD减半，使得坚果一局的爆发期变多，正面能力更上一层楼。至于死亡出租车队没了就没了呗，反正坚果本来机动性就属于垫底那一块。

---

## 威望3：母舰强化

**推荐度**：⭐⭐⭐⭐⭐（极高）

**效果**：
- **母舰可以被召唤**
- **群体传送冷却减少**
- **不再召唤毁灭者**

**详细效果**：
- 母舰：可召唤，拥有强大的技能
- 群体传送：冷却大幅减少
- 毁灭者：不再召唤
- 群体传送不再传送友军单位

**实战评价**：
坚果的主战威望。这个威望给坚果的提高非常显著。首先，母舰相当于一个额外的英雄单位，大幅提高了坚果的前期能力。其次，母舰的常驻使得坚果可以频繁使用群体传送，极大地改善了坚果部队的机动性。最后，红虚空完爆先锋的持续AOE输出能力使得坚果再也不必害怕两张僵尸图了。
