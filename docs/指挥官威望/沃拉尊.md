# 沃拉尊 (Vorazun)

## 威望1：时间停止强化

**推荐度**：⭐⭐（较低）

**效果**：
- **时间停止可以对目标施放**
- **时间停止会在效果生效地点复活所有阵亡的暗影卫队**
- **禁用群体召回**

**详细效果**：
- 时间停止变为可瞄准施放
- 暗影卫队在时间停止生效地点复活
- 失去召回技能

**实战评价**：
沃拉尊应该要学会使用各种手段规避战损，而不是寄希望于用一个青春版的给我死吧提升部队坦度。禁用群体召回严重影响了沃拉尊的许多战术的执行，属实是得不偿失。

## 威望2：红球强化

**推荐度**：⭐⭐⭐（一般）

**效果**：
- **时间停止持续时间内每秒使敌人损失生命值**
- **该效果无法致死**

**详细效果**：
- 时间停止增加持续伤害效果
- 每秒对敌人造成一定生命值损失
- 伤害上限：无法致死

**实战评价**：
这个威望的本意是好的，奈何红球（执政官）有着和电兵几乎一样的各种缺陷。主战兵种的底子不足直接导致这个威望由凯文东希望的法师大队变成了全员刮痧。但是面对双出时效果还算勉强能用。另外由于黑死病的特性导致这个威望下沃拉尊的部队中了黑死后会剩一滴血不死，如果操作很好的情况下可以考虑使用这个威望对抗黑死病。

## 威望3：暗影卫队强化

**推荐度**：⭐⭐⭐⭐⭐（极高）

**效果**：
- **暗影卫队的持续时间延长**
- **友方单位被召回到最近的星灵枢纽或黑暗水晶塔**
- **友军恢复全部的生命值和护盾值**
- **战斗单位造成的伤害降低**

**详细效果**：
- 暗影卫队持续时间：大幅延长
- 召回效果：友军召回并完全恢复生命/护盾
- 负面效果：战斗单位伤害降低

**实战评价**：
沃拉尊的主战威望，很罕见的无负面威望。由于沃拉尊第一个时停大部分情况下是好了不久就放，因此暗影卫队的持续时间不但没有减少，反而延长了一段时间。极大提高了沃拉尊的偷鸡能力和对经济因子的抗性。
