# 其他指挥官精通、威望融合总览

日期：2026-05-27

## 范围

本文汇总除雷诺外 17 个官方合作指挥官的“强度融合版”设计方向，统一按满级最终态书写，不再把 1 级与 15 级拆成两套玩法态。雷诺已经单独细化，见：

```text
docs/指挥官威望/雷诺精通威望加点融合设计-2026-05-27.md
```

本文是设计总览，不是实装闭包。原则和雷诺一致：

1. 等级默认按 15 级全解锁。
2. 精通默认 6 项全部按 30 点满点应用。
3. 威望不直接启用官方 `PlayerPrestige`，必须拆成正面收益、负面代价、禁用项、补充升级和运行时 hook。
4. 默认取正面收益，不取负面代价；少数“代价也想保留”的情况需要用户单独确认。
5. 所有费用、前置、禁用能力、召唤逻辑、面板冷却和单位行为都要继续追 CASC 闭包或实机验证。

## 数据来源

本轮只使用：

```text
游戏数据/官方合作指挥官/commanders/<Commander>/
references/sc2-build-96883-casc-export/
```

不使用 `合作指挥官版起义狂潮/` 作为设计依据。该目录是半成品测试实现，只能作为单独标注的实现线索。

## 通用实现建议

每个指挥官建议生成一个融合 profile：

```text
<Commander>AllPositiveFusion
  LevelMode = FullLevel15
  MasteryMode = AllSixMax
  PrestigeMode = SelectedPositive
  ApplyOrder = BaseCommander -> LevelUnlocks -> Masteries -> PositivePrestige -> Compensation -> Verify
```

日志统一使用：

```text
[XM_DBG][INFO][POWER_FUSION_APPLY] commander=<Commander> profile=<Commander>AllPositiveFusion
[XM_DBG][INFO][POWER_FUSION_MASTERY] commander=<Commander> upgrade=<MasteryUpgrade> level=30 result=ok
[XM_DBG][INFO][POWER_FUSION_PRESTIGE] commander=<Commander> source=<PrestigeId> keep=<effects> skip=<negativeEffects> result=ok
[XM_DBG][WARN][POWER_FUSION_VERIFY] commander=<Commander> field=<field> result=needs-casc-audit
```
