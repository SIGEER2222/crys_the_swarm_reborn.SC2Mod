## 阅读规则

1. 官方与当前 Mod 的对比，默认按满级 `power_fusion` 看。
2. `7v1` 只作为实现参考层，不作为官方设计基准。
3. 当前 Mod 中“建筑/单位计数多于官方”不必然是 bug。
   - 可能只是私有主基地、工人、爬行体、变形态、英雄壳或战役英雄被纳入 runtime 名册。
4. 真正优先级更高的缺口看三类：
   - 官方默认科技能力在当前 Mod 中没有落到任何可见面板能力闭包
   - 建筑/单位按钮数远低于官方
   - 当前 Mod 出现明显共享污染，尤其是人族通用兵营 / 工厂 / 研究链混入非官方 roster

## 指挥官逐项结论

### 阿巴瑟 / `Abathur`

- `7v1` 参考值：
  - `SpawnRace=Zerg`
  - `CoopCasterAbathur`
  - 默认能力 6 条：`MutaliskMorphToDevourer`、`MutaliskMorphToGuardian`、`TrainQueen`、`MorphRoachToRavager`、`SpireResearch,6`、`MorphRoachVileToRavager`
- 当前 Mod 现状：
  - 私有基地和科技壳已经远超 `7v1`，这是方向正确的
  - 但官方导出里的 6 条默认科技能力，在当前导出里仍无法按原始 ID 落到任一面板能力闭包
  - 单位按钮 `55 -> 47`、产出对象 `26 -> 8`，说明进化 / 研究 / 单位技能链仍薄于官方
- 判断：
  - `Roach`、`RoachCorpser` 不能直接当缺口；单页文档已经明确当前满级口径收敛到 `RoachVile -> RavagerAbathur`
  - 真缺口在“默认科技能力挂载”和“按钮 / 产出闭包”

### 阿拉纳克 / `Alarak`

- `7v1` 参考值：
  - `SpawnRace=Prot`
  - `CoopCasterAlarak`
  - 英雄 `AlarakCoop`
  - 英雄结构 `AlarakReviveBeacon`
  - 默认能力 2 条：`AlarakStructureOvercharge`、`CyberneticsCoreResearch,6`
- 当前 Mod 现状：
  - 建筑和单位 roster 数量已与官方对齐
  - 额外多出的 1 个英雄，来自当前 Mod 把阿拉纳克本体明确纳入 runtime，这不是负向缺口
  - 剩余问题主要是默认能力 2 条还没按官方 raw ID 命中当前导出
- 判断：
  - 属于“比较接近闭合，但还要做一次官方 raw ID 对齐和英雄实机验证”的状态

### 阿塔尼斯 / `Artanis`

- `7v1` 参考值：
  - `SoACasterArtanis`
  - 默认能力 6 条：`SOAPylonPower`、`SOAOrbitalStrikeActivate`、`SOAOrbitalStrikeTargetingDummy`、`SOAOrbitalStrikeExecute`、`SoASuperShield`、`RoboticsBayResearch,8`
- 当前 Mod 现状：
  - 建筑数已对齐；单位数 `7 -> 9`，多出的 `Tempest` / `Reaver` 暂不直接判负向
  - 但建筑按钮 `36 -> 22`
  - 官方默认能力 6 条未按 raw ID 落到当前导出
- 判断：
  - 当前主要不是 roster 问题，而是 SoA 面板 / 建筑研究闭包偏薄

### 菲尼克斯 / `Fenix`

- `7v1` 参考值：
  - `SoACasterFenix`
  - 英雄结构 `FenixAltarOfPsiStorms`

  - 单位数接近，额外 6 个英雄属于当前 Mod 将 champion / suit runtime 化的结果

- 判断：
  - 不是“没接 Fenix”，而是“英雄和冠军先接了，基础生产 / 研究 / champion 科技闭包还偏薄”

  - 文档里已写明英雄主链静态口径接近闭环；剩余重点应放在 army closure 和实机验证

## 结论

这 11 个指挥官里，当前 Mod 最大的共性问题不是“完全没接入”，而是下面三类：

1. 私有 roster 和初始化已经先走了一步，但官方默认科技 / 面板 / 研究 / 按钮闭包没有同步补齐。
2. 个别指挥官已经开始做增强或战役英雄接入，导致表面数量更大，但不代表官方基础链就已经完整。
3. 人族和部分虫族存在两种相反风险：
   - `Raynor / Karax / Zagara / Zeratul / Kerrigan` 更像“功能偏薄”
   - `Swann` 更像“共享污染偏重”

后续如果要进入“动手修”的阶段，建议不要按文件散修，而是固定走这条闭包：

```text
官方默认能力 / 建筑 / 单位 / 英雄
-> 7v1 是否已有成熟接法
-> 当前 Mod roster / opener / PlayerCommanders
-> Button / CardLayout
-> Ability
-> Effect / Behavior / Validator / Requirement / Upgrade
-> 产出单位 / 召唤物 / 形态 / 复活 / 顶栏承载单位
```
