# 指挥官精通

日期：2026-05-27

## 职责边界

本模块负责指挥官 6 项精通的声明、默认满点、最终效果、作用对象和测试验证。

当前设计目标不是还原玩家 Bank 加点，而是在战役 mod 中默认使用“6 项精通全部 30 点”的强度融合方案。

## 应用规则

默认：

```text
DefaultFusionLevel = 30
```

执行顺序：

```text
ApplyCommanderFullLevel
  -> ApplyCommanderAllMasteries
  -> ApplyCommanderPrestigeEffects
  -> ApplyRuntimeHooks
```

精通不能依赖玩家 Bank。最终值由 profile 或生成工具确定。

## 效果类型

精通常见影响：

- 英雄攻击、技能伤害、生命值。
- 普通兵种攻击速度、生命值、护甲。
- 顶部技能冷却、充能、持续时间。
- 研究费用、生产费用、建造时间。
- 特殊资源或特殊机制速度。

效果要标记 owner：

```text
panel
hero
unit
building
tech
special_mechanic
runtime_hook
```

## 测试台验证

测试场景：

```text
mastery_smoke
power_fusion_mastery
```

验证项：

1. 6 项精通都能读取。
2. 每项默认等级为 30。
3. 对应升级能应用到玩家。
4. Catalog-only 效果能看到最终字段。
5. runtime-hook 效果能输出最终值。
6. 被精通影响的面板、英雄、单位、科技至少各有代表项验证。

## 剩余风险

- 研究费用、生产费用、面板冷却常常不是单纯加 upgrade level 就生效。
- Tooltip 和真实 Catalog/trigger 效果可能不一致。
- 精通和威望可能同时修改同一对象，必须通过强度融合层统一排序。
