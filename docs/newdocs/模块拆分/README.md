## 统一原则

1. 模块文档只定义边界和接入方式，不替代具体指挥官闭包审计。
2. 指挥官差异优先写 profile，不散落到地图和科技建筑。
3. `XMFinal.SC2Mod` 是 runtime owner，地图只传场景语义。
4. 需要动态行为时使用 commander hook，但 hook 必须有 profile 入口和日志。
5. 当前指挥官默认是 15 级，不从 1 级开始。
6. 测试台默认验证强度融合后的最终状态；需要排查官方基础状态时再显式跑 `initial` 阶段。
