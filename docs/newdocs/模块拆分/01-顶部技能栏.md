# 顶部技能栏

日期：2026-05-27

## 职责边界

顶部技能栏负责玩家不选中单位时也能使用的指挥官技能，例如轨道轰炸、休伯利安、女妖空袭、时间停止、太阳能射线、诺娃核弹等。

它不负责：

- 地图剧情触发。
- 英雄单位命令卡上的普通技能。
- 科技建筑研究按钮。
- 指挥官精通和威望的最终取舍。

精通、威望、等级对顶部技能的影响，只能作为修正输入接入，不应让面板自己决定这些规则。

## 运行时入口

```galaxy
XM_InitCommanderPanel(player, commander)
XM_RefreshCommanderPanel(player, commander)
XM_InvokeCommanderPanelAbility(player, commander, panelAbilityId, target)
XM_UpdateCommanderPanelModifiers(player, commander)
```

Dialog 控件可以统一创建，但按钮来源必须来自 profile。点击按钮后由统一入口转发到 caster ability 或 runtime hook。

## 强度融合接入

顶部技能必须读取强度融合后的最终值：

- 15 级解锁后的可用技能。
- 6 项精通全满后的冷却、充能、费用、伤害、持续时间。
- 威望正面收益带来的冷却、充能、目标范围、额外效果。
- 跳过威望负面后不应残留的禁用、费用增加、冷却增加。

例如雷诺 P3 的空军人口加速顶部技能充能，应由 `CommanderPrestigeEffectProfile` 声明，最终由 panel modifier 或 runtime hook 生效。

## 测试台验证

测试场景：

```text
panel_smoke
power_fusion_panel
```

验证项：

1. caster 单位存在。
2. 所有按钮能按 profile 创建。
3. 按钮可见/禁用状态符合等级、精通、威望。
4. 冷却、充能、能量消耗为强度融合后的最终值。
5. 点选类技能能进入目标选择并下发能力命令。
6. 触发器类技能能调用对应 runtime hook。

## 剩余风险

- Dialog/top-bar 状态在同局切换 commander 时可能残留。
- 部分面板技能不是纯 ability command，可能需要 runtime target forwarding。
- 精通和威望对面板的影响必须追 CASC 或实机日志，不能只看 tooltip。
