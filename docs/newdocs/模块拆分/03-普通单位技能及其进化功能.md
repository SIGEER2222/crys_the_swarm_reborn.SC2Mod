# 普通单位技能及其进化功能

日期：2026-05-27

## 职责边界

本模块负责普通兵种的主动技能、被动技能、武器行为、升级后能力变化，以及单位演化、变体、形态转换。

典型场景：

- 阿巴瑟蟑螂、宿主、飞蛇等单位技能。
- 阿巴瑟终极进化。
- 扎加拉爆虫、腐化者等特殊变体。
- 兵种升级后获得新能力或替换单位。

它不负责英雄形态，也不负责顶部面板技能。

## 演化类型

```text
morph
trainMorph
upgradeVariant
triggerReplace
```

原则：

1. 官方原本是 `CAbilMorph` 的，优先保留原生 morph。
2. 需要茧、进化时间、完成提示时使用 `trainMorph`。
3. 只是属性增强，不换单位，使用 upgrade 或 behavior。
4. `ReplaceUnit` 只作为兼容层，不能作为新增演化默认方案。

## 满级接入

满级后单位清单可能变化，因此普通单位模块必须和 `CommanderRosterProfile` 协作：

- `initial`：基础单位。
- `level15`：当前默认 15 级状态下的单位和变体。
- `power_fusion`：精通全满和威望正面融合后的最终单位清单。

## 测试台验证

测试场景：

```text
unit_ability_smoke
evolution_smoke
fusion_final_units
```

验证项：

1. 单位能创建。
2. 命令卡按钮存在。
3. Ability、Effect、Behavior、Actor、Sound 闭包完整。
4. 主动技能能释放，冷却和消耗正确。
5. 被动技能能挂行为或 validator。
6. 演化后目标单位正确。
7. 演化后生命、能量、护盾、控制组、经验、生物质、精华等状态按声明保留。

## 剩余风险

- 演化状态保留最容易出问题，尤其是控制组、自定义值、生物质、精华。
- 只创建单位不等于技能闭包正确，必须至少释放一次主动技能。
- 满级变体和威望变体需要单独进入最终 roster。
