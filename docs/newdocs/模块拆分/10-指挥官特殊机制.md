# 指挥官特殊机制

日期：2026-05-27

## 职责边界

本模块负责跨单位、跨建筑或跨地图持续存在的 commander 特殊机制，例如德哈卡精华、阿巴瑟生物质、泰凯斯小队、斯台特曼卫星、泽拉图神器碎片。

这类机制通常不能只靠 Catalog 静态表达，需要 profile + runtime hook + 日志。

## 运行时入口

```galaxy

XM_UpdateCommanderSpecialMechanic(player, commander, mechanicId)
XM_OnCommanderSpecialMechanicEvent(player, commander, mechanicId, eventKind)
XM_VerifyCommanderSpecialMechanic(player, commander, mechanicId)
```

## 强度融合接入

特殊机制需要读取：

- 15 级解锁。
- 精通全满后的资源获取、上限、冷却、数值修正。
- 威望正面收益。
- 被跳过的威望负面效果。

例如：

- 德哈卡精华影响等级、技能、属性和克隆。
- 阿巴瑟生物质影响单位属性、终极进化和测试台生成单位。

## 测试台验证

测试场景：

```text
special_mechanic_smoke
biomass_smoke
essence_smoke
artifact_smoke
```

验证项：

1. 机制初始化成功。
2. 特殊资源初始值正确。
3. 获取、消耗、同步事件能触发。
4. 受影响单位行为正确。
5. 精通和威望修正进入最终值。
6. 同局切换 commander 时能清理或重置测试状态。

## 日志

```text
[XM_DBG][INFO][SPECIAL_MECHANIC_INIT] commander=Abathur mechanic=Biomass result=ok
[XM_DBG][INFO][SPECIAL_RESOURCE_SYNC] commander=Dehaka mechanic=Essence value=120 level=15 result=ok
[XM_DBG][ERROR][SPECIAL_MECHANIC_HOOK_MISSING] commander=Zeratul mechanic=Artifact hook=OnArtifactFound result=missing
```

## 剩余风险

- 这类机制常跨多个模块，最容易出现 owner 不清。
- 同局测试可能残留全局变量、触发器、计时器。
- 特殊资源和单位状态同步必须实机验证。
