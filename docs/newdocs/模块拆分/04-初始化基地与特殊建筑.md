# 初始化基地与特殊建筑

日期：2026-05-27

## 职责边界

本模块负责地图开局时为指定 commander 初始化基地、工人、第二建筑、caster、特殊建筑和开局奖励。

特殊建筑包括但不限于：

- 思旺钻机。
- 凯拉克斯能量体系相关建筑。
- 阿巴瑟毒巢或生物质相关初始化对象。
- 斯台特曼卫星体系入口。

地图只负责传入场景语义，不应该知道每个 commander 具体生成什么。

## 运行时入口

```galaxy
XM_InitCommanderStandardBase(player, commander, point)
XM_InitCommanderSpecialStructures(player, commander, scenarioKind)
XM_CreateCommanderScenarioSquad(player, commander, scenarioKind, point)
XM_RunCommanderInitHook(player, commander, hookKind)
```

调用方向：

```text
Map
  -> XM_InitCommanderStandardBase(player, commander, point)
  -> XMFinal 读取 profile
  -> 创建基地/工人/特殊建筑
  -> 执行 commander hook
```

## 特殊建筑口径

特殊建筑不能散落在地图 if/else 中。它要声明：

- 是否随基地初始化。
- 是否只在特定地图或场景存在。
- 是否需要顶栏 caster 或全局触发器。
- 是否受等级、精通、威望影响。
- 是否需要同局切换时清理。

## 测试台验证

测试场景：

```text
standard_base
special_structure_smoke
```

验证项：

1. 基地单位正确。
2. 工人正确。
3. 第二建筑或特殊建筑正确。
4. 顶部技能 caster 正确。
5. 特殊建筑命令卡、行为、攻击或被动功能可用。
6. 同局切换前能清理测试单位组。

## 剩余风险

- 特殊建筑常常绑定全局触发器或面板技能，同局切换可能残留。
- 一些地图没有标准基地，必须通过 `ScenarioKind` 区分。
- 特殊建筑如果依赖地图区域或任务目标，测试台只能验证基础闭包。
