# 特定地图运输机空投单位

日期：2026-05-27

## 职责边界

本模块负责特定地图中的运输机、货舱、空投单位、救援单位和地图场景小队。

地图只描述场景，例如 `cargo_light`、`cargo_heavy`、`cargo_air`，不直接写每个 commander 的货舱单位。


## 场景类型

```text
cargo_light
cargo_heavy
cargo_air
no_base_light
no_base_heavy
bonus_reward
air_support
replacement_squad
```

运输机单位选择应基于 commander 的最终 roster。当前 commander 默认 15 级，强度融合默认使用 `power_fusion` 阶段；如果地图剧情要求弱化单位，要显式声明专用场景或审计用 `LevelStage = initial`，不能把 `initial` 当作默认状态。

## 运行时入口

```galaxy
XM_CreateCommanderCargoSquad(container, commander, scenarioKind)
XM_CreateCommanderMapDrop(player, commander, mapId, scenarioKind, point)
XM_CreateCommanderScenarioSquad(player, commander, scenarioKind, point)
```

## 测试台验证

测试场景：

```text
cargo_light
cargo_heavy
cargo_air
bonus_reward
air_support
```

验证项：

1. 每个 commander 对应场景能读取 loadout。
2. 运输机货舱单位存在。
3. 数量正确。
4. 单位所有权正确。
5. 空投后单位可控。
6. 缺少专用 loadout 时能走 fallback，并输出警告。

## 剩余风险

- 运输机地图常有剧情专用限制，不能只按通用 roster 判断。
- 同一个 commander 在不同地图可能需要不同 loadout。
- 货舱单位如果使用满级最终形态，可能破坏剧情难度；需要由场景显式决定。
