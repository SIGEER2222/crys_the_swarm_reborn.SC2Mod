# 指挥官建筑

日期：2026-05-27

## 职责边界

本模块负责 commander 的建筑清单、建筑替换、训练来源、建筑技能、建筑被动行为和满级/威望后的建筑变化。

它不负责具体科技升级效果，但要声明建筑承载哪些训练能力和研究能力。

## 建议 Profile

```text
CommanderBuildingProfile
CommanderBuildingAbilityProfile
CommanderBuildingTrainProfile
CommanderBuildingStageProfile
CommanderBuildingBehaviorProfile
```


## 建筑分类

```text
base
production
tech
defense
special
panel_caster
map_only
```

特殊建筑如思旺钻机应标记为 `special`，不要伪装成普通科技建筑。

## 和其它模块关系

| 关系 | Owner |
|---|---|
| 开局生成 | 初始化基地与特殊建筑 |
| 训练哪些兵种 | 指挥官兵种 |
| 研究哪些升级 | 科技建筑及其升级选项 |
| 建筑自动维修/灭火 | 指挥官个性化机制 |
| 顶部技能 caster | 顶部技能栏 |

## 测试台验证

测试场景：

```text
full_buildings
building_abilities
building_train_smoke
```

验证项：

1. 建筑能创建。
2. 模型、Actor、选择圈正常。
3. 命令卡按钮存在。
4. 训练能力引用的单位存在。
5. 研究能力引用的升级存在。
6. 满级和威望后新增/替换建筑正确。

## 剩余风险

- 合作指挥官的建筑常有专属版本，不能直接套战役/对战建筑。
- 训练能力、研究能力、Requirement、Button 必须一起验证。
- 建筑被动机制可能属于个性化机制，不应写死在建筑 profile 中。
