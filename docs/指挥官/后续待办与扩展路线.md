# 后续待办与扩展路线

日期：2026-05-22

这份文档替代原先过大的“未完成合作指挥官移植规划清单”。旧稿保留在 `archive/`，这里仅保留当前还值得执行的任务。

## 第一优先级：把已接入的两名指挥官做扎实

### 阿巴瑟

1. 标准基地图 live 验证：
   - 孵化场、工蜂、王虫
   - 工蜂采矿
   - 基础训练链
2. 顶部面板 live 验证：
   - 毒巢
   - 修复
3. 生物质完整闭环：
   - 掉落
   - 拾取
   - 叠层
   - 属性增益
   - 终极进化
4. 继续过无基地图和特殊分支图

### 凯瑞甘

1. 标准基地图验证：
   - 开局虫族基地链
   - `K5Kerrigan`
   - `CoopCasterKerrigan`
2. 测一个基础英雄技能
3. 回归关键特殊图：
   - `traynor01`
   - `ttosh03b`
   - `ttychus03`
4. 决定是否继续做凯瑞甘专属顶部面板，而不是长期停留在通用虫族模板

## 第二优先级：整理通用能力，而不是逐图散改

在继续增加新指挥官前，更建议先补几类公共能力：

1. 更稳定的标准开局 helper
2. 无基地图给兵 helper
3. 运输图给 cargo helper
4. 阵容替换 helper
5. 顶部面板模板的可复用模式

这样后续再加新指挥官时，地图工作量会明显下降。

## 第三优先级：后续扩展到更多指挥官

旧规划里列出了较多未完成指挥官。按当前工程现实，推荐顺序应更保守：

1. `Alarak`
   - 已有 `XMAlarak.SC2Mod`，距离可接入状态最近。
2. `Raynor`
   - 资源最常见，战役贴合度高。
3. `Zagara`
   - 虫族体系与当前阿巴瑟、凯瑞甘积累有重叠。
4. `Artanis`
5. `Karax`
6. `Vorazun`
7. `Fenix`
8. `Zeratul`

这个顺序不是强制，但有两个原则：

- 先做已有模组或资源复用度高的。
- 先做系统复杂度较低的，再做强依赖英雄/碎片/多形态系统的。

## 不再建议继续保留的大而散写法

原始旧规划的问题不是没有价值，而是把三类内容混在了一起：

1. 愿景
2. 当前真实状态
3. 逐图拆任务

以后更建议拆成三份：

- 当前状态文档
- 真正要执行的待办文档
- 历史规划归档

这样不会再出现“同一份文档里既写未完成，又夹杂已经完成或已经失效的判断”。
