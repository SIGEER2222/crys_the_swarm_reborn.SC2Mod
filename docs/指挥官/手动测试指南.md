# 指挥官手动测试指南

## 前置条件检查

在开始测试前，请确认：
1. ✅ SC2已安装在 `E:\SC2\SC2new\StarCraft II\`
2. ✅ 地图和Mod已同步到Live目录
3. ✅ Launcher两行布局已修复

## 测试流程

### 第一步：启动Launcher

1. 关闭所有正在运行的SC2进程
2. 打开命令提示符或PowerShell
3. 运行以下命令：
   ```
   "E:\SC2\SC2new\StarCraft II\Support64\SC2Switcher_x64.exe" "E:\SC2\SC2new\StarCraft II\Maps\XM\Launcher.SC2Map"
   ```

### 第二步：验证Launcher界面

启动后，检查：
- [ ] 能看到两行共18个指挥官按钮
- [ ] 所有指挥官头像正常显示
- [ ] 没有按钮溢出屏幕外

### 第三步：选择指挥官

按照建议顺序逐个测试：
1. Raynor (雷诺) - 控制样本
2. Kerrigan (凯瑞甘)
3. Fenix (菲尼克斯)
4. Artanis (阿塔尼斯)
5. Karax (凯拉克斯)
6. Zagara (扎加拉)
7. Vorazun (沃拉尊)
8. Zeratul (泽拉图)
9. Dehaka (德哈卡)
10. Mengsk (蒙斯克)
11. Mira (米拉·韩)
12. Nova (诺娃)
13. Stetmann (斯台特曼)
14. Stukov (斯托科夫)
15. Swann (斯旺)
16. Tychus (泰凯斯)
17. Alarak (阿拉纳克) - 已验证
18. Abathur (阿巴瑟) - 已验证

### 第四步：选择地图和难度

1. 在Launcher中选择要测试的指挥官
2. 点击"自由日"地图 (thanson01.SC2Map)
3. 选择难度
4. 再次点击地图开始游戏

### 第五步：游戏内验证

游戏启动后，检查：
- [ ] 能正常进入游戏
- [ ] 没有ScriptError提示
- [ ] 没有异常Alerts
- [ ] 基地/工人/基础建筑正确替换
- [ ] 初始训练链可点击
- [ ] 主要技能面板正常

### 第六步：验证Bank文件

1. 打开文件夹：`%USERPROFILE%\Documents\StarCraft II\Banks\`
2. 检查文件：`CampaignXCore.SC2Bank`
3. 确认`<Key name="Commander">`下的值与您选择的指挥官一致

## 单图测试台建议

后续建议新增一张专用测试地图：

```
合作指挥官版起义狂潮\Maps\XM\CommanderTestBench.SC2Map
```

目的：一次启动 SC2 后，在同一张地图里点击不同指挥官，依次调用专用初始化器，验证基地、工人、第二建筑、caster、英雄、运输机货舱、无基地小队、奖励单位、全建筑、全单位、英雄形态和面板闭包。

建议第一版只做这些按钮：

| 按钮 | 用途 |
|------|------|
| 指挥官列表 | Raynor / Nova / Abathur 先做试点，再扩展全部 |
| 清理 | 删除上一轮测试单位，清空测试 unit group |
| 标准基地 | 调用标准基地初始化，验证基地、工人、第二建筑、caster、英雄 |
| 运输机 | 生成运输机/货舱，验证 cargo_light / cargo_heavy / cargo_air |
| 全单位 | 展示该指挥官核心单位、建筑、英雄、特殊单位 |
| 英雄形态 | 验证诺娃形态、德哈卡等级、泰凯斯小队等状态 |
| 面板技能 | 验证 caster、顶部技能按钮和目标转发 |
| 跑全量 | 按指挥官和场景循环跑冒烟测试 |

测试台应输出 `[XM_DBG][TEST_*]` 日志，例如：

```
[XM_DBG][INFO][TEST_COMMANDER_SET] commander=Nova player=1 source=TestBench result=ok
[XM_DBG][INFO][TEST_SCENARIO_START] commander=Nova scenario=standard_base result=ok
[XM_DBG][ERROR][TEST_MISSING_UNIT] commander=Kerrigan scenario=cargo_light unit=CoopZerglingRaptor result=missing
[XM_DBG][INFO][TEST_SCENARIO_DONE] commander=Nova scenario=standard_base units=18 warnings=0 errors=0 result=ok
```

注意：同一局切换指挥官适合做高覆盖冒烟测试，但不是完全干净的新局测试。升级、Bank、全局触发器、计时器、caster group 和 Dialog 面板可能残留。最终仍要抽样进真实战役地图确认任务语义。

## 快速启动参考

### Launcher启动命令
```cmd
taskkill /f /im "SC2_x64.exe"
timeout /t 2
"E:\SC2\SC2new\StarCraft II\Support64\SC2Switcher_x64.exe" "E:\SC2\SC2new\StarCraft II\Maps\XM\Launcher.SC2Map"
```

### Bank文件位置
```
%USERPROFILE%\Documents\StarCraft II\Banks\CampaignXCore.SC2Bank
```

### 游戏日志位置
```
%USERPROFILE%\Documents\StarCraft II\GameLogs\
```

## 问题排查

### 如果Launcher按钮显示不全
- 检查Launcher.SC2Map是否为最新的两行布局版本
- 确认两行布局修复已同步到Live目录

### 如果有ScriptError
- 检查游戏日志：`%USERPROFILE%\Documents\StarCraft II\GameLogs\`
- 查找最近的ScriptError.txt文件

### 如果Bank文件Commander值不对
- 手动编辑CampaignXCore.SC2Bank文件
- 找到`<Section name="Ach">`下的`<Key name="Commander">`
- 修改Value的string属性为正确的指挥官名字

## 备注

- 测试时建议按顺序进行
- 每次测试后截图保存到工作区
- 发现问题立即记录，不要继续下一个
