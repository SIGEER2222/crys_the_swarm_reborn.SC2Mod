# 合作指挥官兵种建筑对照审计

日期：`2026-05-25`

## 结论先行

- 以 `docs/维基指挥官/兵种` 为合作模式参考源，对 `合作指挥官版起义狂潮/Mods/XM` 当前 18 指挥官做“兵种/建筑条目是否能在本地模块中落到数据或本地化证据”审计后，`17` 个有参考目录的指挥官现在都能直接命中全部参考兵种/建筑名。
- 本轮已把之前 `8` 个“别名/ID 命中”的指挥官统一收口到模块本地化层，当前不再有“仅靠内部 ID / 英文别名才能确认”的兵种/建筑条目。
- `XMKerrigan.SC2Mod` 原 `GameStrings.txt` 存在非 UTF-8 编码残留，已重建为 UTF-8 并补齐合作模式兵种建筑名。
- `阿拉纳克 Alarak` 已在当前 18 指挥官基线内，但 `docs/维基指挥官/兵种` 没有对应参考目录，因此本次只能记为“参考侧缺口”，不能直接做同口径对照。

## 范围与口径

当前侧：

- `合作指挥官版起义狂潮/Mods/XM`
- 指挥官基线取自 `docs/指挥官/总览.md`

参考侧：

- `docs/维基指挥官/兵种`
- 主要使用每个指挥官目录下的 `units.json`、`buildings.json`
- `菲尼克斯 Fenix` 目录只有 `units.json`，没有 `buildings.json`

本次审计不覆盖：

- 英雄本体技能、顶部面板、威望、数值平衡
- 地图开局替换、运行时分支、Bank/Launcher 选择链
- “模块里有这个词”之外的实机可训练/可建造验证

本次审计定义：

- `直接命中`：参考条目中文名可直接在目标 `XM*.SC2Mod` 的本地文本或数据文件中命中。
- `别名/ID 命中`：中文名未直接命中，但能在同模块内命中明确的内部 ID、英文名或合作模式别名。
- `未解决`：既没有中文直接命中，也没有足够明确的别名/ID 证据。
