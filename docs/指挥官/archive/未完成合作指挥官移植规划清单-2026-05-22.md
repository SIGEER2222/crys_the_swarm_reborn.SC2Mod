# 总体接入原则

## 公共层必须做

每个新指挥官都至少需要：

1. 新建或启用 `XM<Commander>.SC2Mod`。
2. 从官方 `starcoop.sc2mod` 导入对应 catalog 数据。
3. 在 `XMCore.SC2Mod/Base.SC2Data/GameData/UserData.xml` 中增加 `CommanderAch/<Commander>`。
4. 在 LauncherAuto 的 `CommanderPreset` 中追加候选。
5. 修改 Launcher 的 `gv_commanderNum`。
6. 在 `XMFinal.SC2Mod/Base.SC2Data/LibE0EAE146.galaxy` 中增加标准基地/英雄/面板初始化分支。
7. 如果指挥官有全局顶部面板，补 `XMCore.SC2Mod/Base.SC2Data/Lib67C0F0E7.galaxy` 的 `CU_GPInit<Commander>`。
8. 逐图补地图脚本中硬编码指挥官分支。
9. 新增验证脚本，例如 `scripts/validate-<commander>-port.ps1`。
10. 新增进度文档。

## 地图分支分类

所有地图按适配方式分 5 类：

| 类型 | 说明 | 处理方式 |
|---|---|---|
| 标准基地图 | 调用 `libE0EAE146_gf_InitializeBase` | 主要依赖 `CommanderAch` 和 `XMFinal` 标准初始化 |
| 无基地英雄图 | 玩家初始体验完全靠脚本给英雄/小队 | 必须在地图脚本中补该指挥官分支 |
| 运输机/货舱图 | 根据指挥官向运输机塞单位 | 必须补 `UnitCargoCreate` 单位 |
| 奖励给兵图 | 事件发生时按指挥官给兵 | 必须补等价兵种 |
| 阵容替换图 | 根据指挥官替换某一方阵容 | 必须补完整阵容 |

# 当前额外注意：Launcher 单文件打包问题

目前工作区 `LauncherAuto.SC2Map` 是解包目录，已能看到新增候选，例如 Kerrigan。

但实际启动命令使用的是：

```text
E:\SC2\SC2new\StarCraft II\Maps\XM\Launcher.SC2Map
```

该路径当前是单文件地图包，不是解包目录。因此仅修改工作区 `LauncherAuto.SC2Map` 不会让游戏内候选立刻变化。

后续所有新指挥官接入 Launcher 时，都必须同时解决：

```text
工作区 LauncherAuto.SC2Map -> 打包/替换 live Launcher.SC2Map
```

否则会出现“工作区候选有，游戏内候选没有”的问题。
