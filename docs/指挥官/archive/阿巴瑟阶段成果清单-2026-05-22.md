# 阿巴瑟阶段成果清单（2026-05-22）

## 当前已经成立的部分

- 阿巴瑟已经接入指挥官候选列表，Launcher 中可以被选择。
- 阿巴瑟头像、成就标题、巅峰标题与描述已经补入，不再只是空名字。
- `XMFinal` 已经存在 `Commander == "Abathur"` 的运行时分支。
- 阿巴瑟顶部面板施法者 `CoopCasterAbathur` 已经接入运行时初始化。
- 顶部面板目标结构已经明确为 2 个主动按钮：
  - `SpawnToxicNest`
  - `AbathurMend`
- `XMAbathur.SC2Mod` 已经承载阿巴瑟专属数据对象，而不是只保留名字：
  - `HatcheryAbathur`
  - `DroneAbathur`
  - `OverlordAbathur`
  - `CoopCasterAbathur`
  - `SpawnToxicNest`
  - `AbathurMend`
  - 生物质、终极进化、共生体相关对象
- `CommanderAch/Abathur` 的 `Upg/Poi` 映射已经补入 `UserData.xml`。
- 默认 debug bank 写盘已经硬关闭，避免继续生成 `XMAbathurDebug.SC2Bank`。
- `XMAbathur` 内旧 runtime 已经停用，阿巴瑟 runtime 入口统一收回到 `XMFinal`。
- `ttychus03` 中原本只给 `Overlord` 的阿巴瑟占位分支已经替换为正式 helper 调用。
- 阿巴瑟相关中文文案中的“预留”占位描述已基本清理。

## 已完成的静态接线

- `XMFinal.SC2Mod` 依赖中已经包含 `XMAbathur.SC2Mod`。
- 阿巴瑟开局单位映射已经指向：
  - `CommandCenter -> HatcheryAbathur`
  - `Worker -> DroneAbathur`
  - `SecondUnit -> OverlordAbathur`
- 阿巴瑟顶部面板模板初始化已经接到 `CU_GPInitAbathur`。
- `CoopCasterAbathur` 在数据层已经具备面板技能按钮布局。

## 目前还未完全收口的部分

- 生物质 runtime 目前仍然是“最小可跑版”，不是完整官方逻辑改造版。
- 现有 `XMFinal` 中已经实现：
  - 敌方死亡掉落生物质
  - 周期扫描拾取
  - 给拾取单位写入自定义值
- 但以下能力还没有完全确认已经闭环：
  - 生物质叠层如何稳定转成正式行为层
  - 生物质成长属性是否完整兑现
  - 终极进化阈值与触发链是否完全接通
  - 死亡返还/转移是否已按目标逻辑收实
- 因此当前状态更接近：
  - “阿巴瑟已经被系统接进来了”
  - 而不是“阿巴瑟玩法已经完整可交付”

## 已识别的主要风险点

- live 中如果看到“能选阿巴瑟，但单位/技能不像阿巴瑟”，优先怀疑 runtime 生物质与技能效果链没有完全兑现，而不是候选接入失败。
- 顶部面板骨架虽然已经在，但技能显示正常不等于技能效果已经完全落地。
- 开局单位映射虽然已改为阿巴瑟专属单位，但仍需 live 再次验证实际生成结果。
- 当前最可能继续出问题的区域仍然是：
  - 生物质成长
  - 终极进化
  - 面板技能实际效果

## 一句话结论

当前可以明确确认的是：

- 阿巴瑟已经不是“只有名字没接线”的状态。
- 阿巴瑟已经进入指挥官候选、运行时识别、模组依赖、面板骨架和基础数据链。
- 现在剩余工作的重点，不是“把阿巴瑟加进去”，而是“把阿巴瑟玩法逻辑补完整”。
