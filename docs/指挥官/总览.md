## 现状判读

- `Abathur` 已经有 runtime、开局、面板、生物质入口和部分地图 helper，但还需要 live 收口。
- `Alarak` 已完成当前阶段的主要数据、成长映射和关键接线修正，可先按“基本可用”停放，后续只做回归和补漏。
- `Kerrigan` 已有模组、依赖、公共接线和地图分支，上一阶段已完成主要静态纠偏，后续按回归和补漏处理。
- `Raynor` 已创建 `XMRaynor.SC2Mod`，并导入 5251 个官方相关 catalog 对象；`CommanderAch/Raynor`、`XMFinal` runtime、实际打包 Launcher 候选和 live 同步均已完成，当前剩余风险是实机回归和特殊地图补漏。
- `Fenix` 已创建 `XMFenix.SC2Mod`，并导入 7496 个官方相关 catalog 对象；`CommanderAch/Fenix`、`XMFinal` runtime、实际打包 Launcher 候选、三套装顶部面板、核心训练链和特殊地图 helper 已完成。当前剩余风险是未做本轮实机抽测，以及完整 `libCOMI` 网络优势/冠军壳体计数还不是逐行官方复刻。
- `Artanis` 已创建 `XMArtanis.SC2Mod`；`CommanderAch/Artanis`、`XMFinal` runtime、Launcher 候选、顶部面板、核心训练链、`SMX2ProtossArtanis` 英雄单位、Guardian Shell 链和特殊地图 helper 已完成。当前剩余风险是未做本轮实机抽测，以及完整官方 `libCOMI` 细节还不是逐行复刻。
- `Zagara` 已接好 runtime、精通映射、候选列表和一批特殊地图 helper；当前剩余风险是 launcher 打包同步、技能实机确认，以及无基地图是否存在重复给兵。
- `Vorazun` 已接好 runtime、CommanderAch、launcher 候选、特殊地图 helper 和基础 mastery 链；当前剩余风险是实机抽测与 launcher 打包同步。
- 其余 4 名未完成指挥官仍主要停留在规划层，缺核心单位/建筑/英雄/面板/地图接线。

## 读法

- 想看“当前能跑到什么程度”，读各自的当前状态文档。
- 想看“为什么这么接”，读 `当前架构与接入原则.md`。
- 想看“下一步先做什么”，读 `后续待办与扩展路线.md`。
- 想看旧判断和阶段差异，去 `archive/`。
