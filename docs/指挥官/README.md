# 指挥官文档索引

本目录只保留当前仍适合作为入口的文档。

## 当前有效

- `当前架构与接入原则.md`
  - 指挥官移植到战役的统一架构、依赖分层、地图接入边界和验证口径。
- `阿巴瑟当前状态.md`
  - 阿巴瑟在当前仓库中的已完成部分、已知缺口和后续验证重点。
- `凯瑞甘当前状态.md`
  - 凯瑞甘模块、依赖、地图分支和当前仍需收口的部分。
- `技能面板移植参考-德哈卡与阿巴瑟.md`
  - 顶部技能面板体系的实现参考，重点对照德哈卡和阿巴瑟。
- `后续待办与扩展路线.md`
  - 还值得继续推进的收尾项，以及后续扩展到更多指挥官时的建议顺序。

## 历史归档

`archive/` 中保留阶段性记录、交接稿、旧规划和原始 GBK 文档，供追溯，不作为当前结论来源。

其中包括：

- 阿巴瑟阶段成果和交接快照
- 两份重复的“战役接入方向”文档
- 大而散的未完成移植规划清单
- 原始的凯瑞甘/面板参考旧稿
- 调试截图

## 使用建议

1. 先看 `当前架构与接入原则.md`。
2. 再按具体指挥官看 `阿巴瑟当前状态.md` 或 `凯瑞甘当前状态.md`。
3. 需要补顶部技能面板时，再看 `技能面板移植参考-德哈卡与阿巴瑟.md`。
4. 需要追旧判断或阶段差异时，再去 `archive/`。
