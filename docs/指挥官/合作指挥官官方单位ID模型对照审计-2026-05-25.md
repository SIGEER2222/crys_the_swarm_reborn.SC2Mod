## 说明

- SameUnitId：当前模块与官方 coop 至少有一个相同的 unit id。
- DifferentUnitId：当前模块中文名落到的 unit id 与官方 coop 中文名落到的 unit id 没有交集，这是最需要优先复核的同名异体风险。
- SameIdDifferentModel：unit id 一样，但当前和官方找到的模型资源没有交集，说明视觉或 actor 继承链可能已漂移。
- Ambiguous：任一侧同名对应多个 unit id，需要继续结合能力链或实机卡片判断主对象。
- Unresolved：至少有一侧只命中了字符串，但没有顺利落到 UnitData.xml 对象。
