# Raynor 当前状态

日期：2026-05-23

这份文档记录 Raynor 当前已经落地的移植状态。当前目标不是完整官方合作模式复刻，而是让 Raynor 在战役 mod 中可选择、可初始化、可使用核心单位/建筑/英雄/顶部面板，并保留后续补漏入口。

## 已经成立

### 独立模组与依赖

- `合作指挥官版起义狂潮/Mods/XM/XMRaynor.SC2Mod` 已创建。
- `scripts/import-official-raynor-data.ps1` 已从官方 `starcoop.sc2mod` 导入 Raynor 相关 catalog 对象。
- 导入摘要：`references/official-raynor-import-summary.tsv`
- 导入对象数：`5251`
- `XMFinal.SC2Mod/DocumentInfo` 与 `DocumentHeader` 已加入 `file:Mods\XM\XMRaynor.SC2Mod`，依赖表数量为 18。
- live 目录已同步 `XMCore.SC2Mod`、`XMFinal.SC2Mod`、`XMRaynor.SC2Mod`。

### Launcher 候选

- 实际启动入口是打包版 `Maps/XM/Launcher.SC2Map`，不是 `LauncherAuto.SC2Map`。
- 当前 `Launcher.SC2Map` 已基于原始 8 候选最小追加 Raynor：
  - `MapScript.galaxy`: `gv_commanderNum = 8`
  - `CommanderPreset` 三个 Count 均为 `9`
  - `Commander Index="8"` = `Raynor`
  - `Por Index="8"` = `UserData/CommanderPreset/ID_Por_008`
  - `CommanderPortrait Index="8"` = `Assets\Textures\ui_btn_commanderportrait_raynor.dds`
- live `E:\SC2\SC2new\StarCraft II\Maps\XM\Launcher.SC2Map` 已同步到同一哈希。

### 成长与运行时

- `XMCore.SC2Mod/Base.SC2Data/GameData/UserData.xml` 已有 `CommanderAch/Raynor`。
- 8 个成就升级已映射到 Raynor 官方升级对象。
- 6 个巅峰项已映射到 Raynor mastery 对象。
- `XMFinal` 已识别 `Commander == "Raynor"`，并设置 `RaynorCommander` 初始升级。
- `InitializeBase` 已创建 `CoopCasterRaynor`、调用 `CU_GPInit("Raynor")`、显示顶部面板，并生成 Raynor 英雄/轻型初始部队。
- 已新增公共 helper：
  - `libE0EAE146_gf_RaynorCreateMapStartSquad`
  - `libE0EAE146_gf_RaynorCreateMapStartSquadInRegion`
  - `libE0EAE146_gf_RaynorCreateCargoSquad`

### 单位、建筑、英雄、面板

已静态命中的关键对象包括：

- 基地/工人：`CommandCenter`、`SCV`
- 基础部队：`Marine`、`Medic`、`Marauder`、`Firebat`
- 机械/空军：`SiegeTank`、`VikingFighter`、`Banshee`、`Battlecruiser`
- 英雄/召唤：`Raynor`、`RaynorCommando`、`DuskWing`、`HyperionVoidCoop`
- 顶部 caster：`CoopCasterRaynor`
- 面板能力：`VoidCoopSummonHyperion`、`BansheeAirstrike`
- 经济能力对象：`CalldownMULE`

当前 Raynor 顶部面板按官方导入数据是两按钮模板：休伯利安与女妖空袭。`CalldownMULE` 存在于 `TerranRaynor` 默认能力命令中，不在这个两按钮顶部面板模板上，不应按“顶部缺第三按钮”直接判失败。

## 剩余风险

- 尚未做本轮实机点击验证。原因是用户希望减少启动游戏打断，当前先以静态和 live 包解包验证收口。
- `traynor01` 已有 Raynor 分支；其余特殊地图还没有逐图实机确认 Raynor helper 是否都符合剧情节奏。
- 完整官方合作 Raynor 的全部威望/精通 runtime 不是本轮目标；当前只完成 XM 成长框架映射与核心可玩链路。
- 若后续实机发现矿骡需要在顶部面板直接显示，需要另开一轮按 XM UI 模板扩展，而不是误改官方两按钮模板。

## 下一步建议

1. 在合适窗口进行一次最小实机验证：启动 Launcher，选择 Raynor，进一张标准基地图。
2. 进图后确认 `CampaignXCore.SC2Bank` 写入 `Ach/Commander=Raynor`。
3. 检查基地/SCV、基础训练链、`CoopCasterRaynor` 两个顶部按钮、Raynor 英雄/初始部队。
4. 再按地图清单补特殊分支，不要一次性大改所有地图。
