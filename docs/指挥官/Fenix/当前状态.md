## 剩余风险

- 尚未做本轮实机点击验证。用户要求减少启动游戏打断，当前先以静态、XML、packed 解包和 live 文件同步验证收口。
- Fenix 官方合作里的完整 `libCOMI` 行为仍比当前 XM runtime 更深：网络优势精确叠层、冠军壳体计数、完整复活动画/传输细节还不是逐行官方复刻。当前版本采用官方数据对象 + XMFinal 最小 runtime，已能支撑面板三套装、核心训练链、地图 helper 和成就解锁冠军对象。
- `FenixProbiusProbe` 是官方特殊/英雄对象，不作为常规采矿农民；常规开局农民必须继续用 `Probe`。
- 本轮额外对照了官方 `starcoop` 的训练链与本地 `XMFenix`：
  - `GatewayTrain / WarpGateTrain` 混用 `SentryFenix / SentryFenixPhasing`
  - `StargateTrain -> Scout`
  - 这些在官方 coop 共享数据里同样成立，因此当前不把它们当作本地 unit id 误接来强改。
- 当前对 Fenix 的后续重点不再是“同名就换成更像净化者的 id”，而是继续做实机验证，确认三套装、冠军人格、基地训练链和特殊地图 helper 的运行表现。
