## 第二步：同步Mod文件

### 方法1：使用robocopy（推荐）

打开命令提示符（CMD），运行以下命令：

```cmd
:: 同步所有指挥官Mod
robocopy "C:\Users\22448\Downloads\重生虫心0.71汉化版（新）\reborn_workrepo\合作指挥官版起义狂潮\Mods\XM" "E:\SC2\SC2new\StarCraft II\Mods\XM" /E /R:1 /W:1

:: 同步所有地图
robocopy "C:\Users\22448\Downloads\重生虫心0.71汉化版（新）\reborn_workrepo\合作指挥官版起义狂潮\Maps\XM" "E:\SC2\SC2new\StarCraft II\Maps\XM" /E /R:1 /W:1

:: 同步Launcher
robocopy "C:\Users\22448\Downloads\重生虫心0.71汉化版（新）\reborn_workrepo\tools\launcher_mpq" "E:\SC2\SC2new\StarCraft II\Maps\XM\Launcher.SC2Map" /E /R:1 /W:1
```

### 方法2：手动复制

如果robocopy不可用，可以手动复制：

1. 复制文件夹 `合作指挥官版起义狂潮\Mods\XM\*` → `E:\SC2\SC2new\StarCraft II\Mods\XM\`
2. 复制文件夹 `合作指挥官版起义狂潮\Maps\XM\*` → `E:\SC2\SC2new\StarCraft II\Maps\XM\`
3. 复制文件夹 `tools\launcher_mpq\*` → `E:\SC2\SC2new\StarCraft II\Maps\XM\Launcher.SC2Map\`

## 第四步：检查Launcher的两行布局

确保Launcher.SC2Map中的MapScript.galaxy包含两行布局的修复：

检查文件：`E:\SC2\SC2new\StarCraft II\Maps\XM\Launcher.SC2Map\MapScript.galaxy`

确认：
- 容器高度是 300（不是 200）
- 有换行逻辑（当 x 偏移 >= 738 时换行）
- 每行 9 个按钮

## 第五步：准备Bank文件（可选）

如果需要预设指挥官，可以编辑：

`%USERPROFILE%\Documents\StarCraft II\Banks\CampaignXCore.SC2Bank`

找到：
```xml
<Section name="Ach">
  <Key name="Commander">
    <Value string="Raynor"/>
  </Key>
</Section>
```

修改string值为你想要测试的指挥官名字。
